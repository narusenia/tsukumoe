# 評価用モデルへのコンパイルと評価パイプライン

- REQ: REQ-CORE-001, REQ-CORE-008
- 単位: M1-03
- 状態: 完了
- 依存: M1-01
- 設計判断: [ADR-0020](../../adr/0020-evaluation-layout.md)
- 仕様: [evaluation.md](../../specifications/evaluation.md)

## 範囲

| 含める | 含めない |
|---|---|
| `Model::compile()` → `CompiledModel`（連続バッファ・オフセット表・デフォーマの評価順） | ドライバ（M1-04）、ボーンとスキニング（M1-05）、物理（M1-06） |
| `Frame`（作業領域）と `Frame::evaluate` | 描画リストの形（M1-07）。M1-03 は頂点・不透明度・描画順・色の配列を出すところまで |
| キーフォーム補間、ブレンドシェイプ、ワープ / 回転デフォーマ、グルー、不透明度の継承 | ワープのベジェ補間、SIMD の明示的な最適化 |
| フレーム評価中にヒープ確保がないこと（テストで検証） | |

## 実装ステップ

1. `CompiledModel` と `Model::compile`
2. `Frame` とキーフォームの補間（重みの計算、メッシュ・デフォーマの値）
3. ブレンドシェイプ
4. デフォーマの世界変換とメッシュ頂点の変換
5. グルーと不透明度・描画順・色
6. 無アロケーションのテスト

## 受入条件

- [x] 無効なモデルはコンパイルがエラーになる
- [x] キーフォームの補間（1 軸・2 軸・範囲外）が期待値と一致する
- [x] ブレンドシェイプ・ワープ・回転・入れ子のデフォーマ・グルー・不透明度の継承が期待値と一致する
- [x] 定常状態のフレーム評価でヒープ確保が 0 回である
- [x] `mise run check` が通る

## 残した制約

- ワープの `bezier` は未実装で、双線形で評価する。M2 で Cubism と比べて決める
- 座標系の細部（ワープ格子外の外挿、回転デフォーマが子に与える変換、デフォーマが属するパーツの扱い）は Tsukumoe 自身の定義で、Cubism と一致するかは M2 で検証する（`evaluation.md`）
- 性能は未計測。SIMD の明示的な最適化もしていない。計測は M1-12
- ボーン・物理は評価に入っていない（M1-05、M1-06）。ドライバは M1-04 で手順 0 として入った
- `CompiledModel` の公開フィールドは、M3 のバイナリ形式を決めるときに見直す
- 無アロケーションのテストは、このクレートのテストバイナリ全体のアロケータを差し替えて計測している（スレッドごとの計数）
