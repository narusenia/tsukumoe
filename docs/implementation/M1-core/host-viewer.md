# ホストの芽: パラメータスライダ付きビューア

- REQ: REQ-TRK-003, REQ-UI-001, REQ-UI-002
- 単位: M1-11
- 状態: 完了
- 依存: M1-09, M1-10（`tsukumoe-ui`、ADR-0025、ADR-0026）
- クレート: `tsukumoe-host`（ライブラリ + バイナリ `tsukumoe-host`）

## 目的

プロジェクトを開き、パラメータをスライダで動かしながら描画を見られるようにする。UI とレンダラの結合（`WgpuSurface` の device で `tsukumoe-gpu` が描く）を確かめ、M4 の配信ホストと M5 のエディタの土台にする。

## 範囲

- `tsukumoe-host <project>`: ディレクトリか zip を開く。ファイル選択ダイアログは作らない
- 左にパラメータ一覧（名前・スライダ・値）、右にビューポート。上部に「リセット」（全パラメータを既定値へ）
- 物理を進める（毎フレーム `advance(dt)`）。パラメータを動かすと物理の出力も追従する
- ビューは「既定姿勢の描画の外接矩形」を、ビューポートの縦横比に合わせて広げたもの。ウィンドウのサイズ変更に追従する
- 範囲外: 透過ウィンドウ・Spout2 / Syphon・仮想カメラ・トラッキング入力（M4）、ズームとパン、モーション再生

## 構成（疎結合）

| 層 | 内容 | UI への依存 |
|---|---|---|
| `viewer` | プロジェクトの読み込み、パラメータの表（名前・範囲・既定値）と現在値、`advance`、描画（`Renderer::render_to_view`）、ビューの計算（`fit_view`） | なし（`wgpu` と `tsukumoe-*` のみ） |
| `app` | ウィンドウ、スライダ、`WgpuSurface`。`viewer` を呼ぶだけ | `tsukumoe-ui` と `wgpui` |

UI ツールキットを替えるときは `app` だけを書き直す。

## 受入条件

- [x] 基準モデル（M1-13）を開き、100 個のパラメータのスライダで姿勢が変わる
- [x] ウィンドウのサイズを変えても、モデルの縦横比が保たれる
- [x] リセットで既定姿勢に戻る
- [x] `viewer` のテスト: パラメータ表の内容、値の設定とリセット、`fit_view` の縦横比、描画物のないモデル、読み込みエラー
- [x] `mise run check` が通る。`viewer` が UI クレートに依存しない

## 検証

窓を開く部分は CI で動かせない（ビルドのみ）。手元の macOS で、基準モデルとスクリーンショットで確認する。

## 結果

- macOS（Apple Silicon）で基準モデル（150 メッシュ・100 パラメータ）を開いて確認した。スライダのドラッグで姿勢が変わり、リセットで初期姿勢と画素が一致し、ウィンドウを細くしても縦横比が保たれた
- Linux / Windows の窓は未確認（CI はビルドのみ）
- パラメータ名が長い場合は 110px で切り詰める。グループ分け・検索・値の直接入力は未対応（エディタ側で扱う）
- 日本語入力（IME）は ADR-0025 に検証結果を記録した。ビューアは文字入力を持たないので、この単位では対応不要
