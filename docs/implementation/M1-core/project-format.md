# JSON プロジェクト形式

- REQ: REQ-FMT-001, REQ-FMT-002, REQ-FMT-003, REQ-FMT-005
- 単位: M1-08
- 状態: 着手中
- 依存: M1-01
- 仕様: [file-formats.md](../../specifications/file-formats.md)
- クレート: `tsukumoe-format`（`tsukumoe-core` に依存を足さない）

## 方針

- 要素どうしの参照は内部の `Id` なので、JSON は名前で参照する専用の型を `tsukumoe-format` に持ち、`Model` と相互に変換する。型から JSON Schema を生成する（`schemars`）
- zip の読み書きは `zip` クレート。どちらも依存の追加を利用者が承認済み

## 段階 1 の受入条件

- [x] 読み込み → 書き出しで内容が変わらない（zip・ディレクトリ）。出力は決定的
- [x] JSON のキー順が安定し、差分が読める形（2 スペース・末尾改行）
- [x] 破損した zip・不正な JSON・危険なパス・サイズ超過でパニックせずエラーを返す（全長の切り詰めと全バイトの反転で確認）
- [x] 新しいメジャーバージョンを拒否し、未知の「無視可」機能を読み、未知の「必須」機能をエラーにする
- [x] 展開ディレクトリを読み書きでき、リンクは辿らない
