## 範囲

| 含める | 含めない |
|---|---|
| 式の構文解析（再帰下降）と命令列へのコンパイル | JSON 形式での入出力（M1-08） |
| 未知の名前・循環・出力の重複・制限超過のコンパイルエラー | 互換モードの切り替え |
| ドライバの評価順（トポロジカル順）と `Frame::evaluate` への接続 | 式の最適化（定数畳み込みなど） |
| 無アロケーションのテスト | 関数の追加、条件分岐、変数 |

## 実装ステップ

1. 字句解析と構文木（`expr.rs`）。構文エラーに文字位置を付ける
2. 構文木 → 命令列。名前の解決、関数と引数の数の検査、スタックの深さの検査
3. ドライバ全体のコンパイル: 評価順、循環・重複の検出、`CompiledModel` への格納
4. `Frame::evaluate` の手順 0 としてドライバを実行
5. 無アロケーションのテスト

- [x] 評価結果が、キーフォームの補間に反映される（ドライバ → 補間の通し）
- [x] 定常状態のフレーム評価でヒープ確保が 0 回である
