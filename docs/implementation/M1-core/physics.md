# 物理（振り子と物理チェーン）

- REQ: REQ-CORE-005
- 単位: M1-06
- 状態: 完了
- 依存: M1-03
- 設計判断: [ADR-0022](../../adr/0022-physics-stage.md)
- 仕様: [physics.md](../../specifications/physics.md)

## 範囲

| 含める | 含めない |
|---|---|
| 固定刻み（1/60 秒）・余りの持ち越し・1 回の上限 | physics3 の読み込み（M2）、Cubism との一致の検証（M2） |
| 振り子（`PendulumGroup`）の運動と入出力 | 衝突（v1.x、ADR-0007） |
| 物理チェーン（関節数・剛性・減衰・重力・風）の運動と入出力 | 入力の刻み内補間 |
| `Frame::advance(model, dt)`、出力パラメータの書き込み | チェーンの角度入力の範囲の調整（定数 `CHAIN_ANGLE_SPAN`） |
| ドライバとの出力の重複をコンパイルエラーにする | |

## 実装ステップ

1. ADR-0022、仕様
2. `CompiledModel` に物理の定義（入力・出力・粒子）
3. `simulate.rs`: 入力の正規化、振り子、チェーン、出力
4. `Frame::advance`、`evaluate` は `dt = 0`
5. テスト

## 受入条件

- [x] 振り子が根の動きに引かれて揺れ、静止すると真下（または角度入力の向き）に落ち着く
- [x] 物理チェーンの関節数・剛性・減衰・重力・風が結果に効く
- [x] 固定タイムステップで、フレームレートに依存しない（刻みの整数倍に分けた `dt` で同じ結果）
- [x] 1 回の `advance` の上限が働く
- [x] 定常状態のフレーム評価でヒープ確保が 0 回である
- [x] `mise run check` が通る

## 残した制約

- **physics3 と一致するかは未検証**。運動方程式は Seimei 自身の定義で、`GRAVITY_UNIT`、`mobility` / `delay` の意味づけは M2 の比較で調整する（REQ-CORE-005 の最初の受入条件は M2 で満たす）
- 物理の出力を読むドライバは 1 フレーム遅れる（ADR-0022）
- 入力の重み・出力の重みは百分率。範囲外や負の値の検査は M1-08（入力境界）で行う
