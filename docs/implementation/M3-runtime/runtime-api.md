# 再生ランタイム（`tsukumoe-runtime`）

- REQ: REQ-RT-001
- 単位: M3-02
- 状態: 完了
- 依存: M3-01
- クレート: `tsukumoe-runtime`（新設。`tsukumoe-core` の評価部分だけに依存し、編集機能・`tsukumoe-format` に依存しない）

## 目的

読み込んだ `.tmod` を再生する薄い API。ロード、パラメータ設定、モーション（レイヤ・フェード・優先度・ループ）、表情、自動動作（まばたき・呼吸）、物理を進め、描画リストを返す。C ABI（M3-03）と WASM（M3-04）はこの API の薄い包みにする。

## 現状の不足

- `playback.rs` はデータ型（Motion / Expression / Pose）だけで、曲線の評価もプレイヤもない
- `.tmod`（M3-01）は評価データだけで、モーション・表情・ポーズを持たない
- 評価器は、パーツの不透明度を外から受け取れない（`part_opacity` はコンパイル済みの固定値）。モーションの `PartOpacity` 曲線とポーズが効かない

## 方針

- **データ**: モーション・表情・ポーズを `.tmod` の無視可セクションとして足す（M3-01 の機能フラグの方式。M3-01 のローダは読み飛ばせる）。M3-01 と同じく POD の平らな配列、パラメータ・パーツは添字で指す。名前は文字列表
- **評価器の追加**: `Frame` にパーツ不透明度の上書き（`set_part_opacity`）を足す。既定は従来どおりコンパイル済みの値で、既存の結果は変えない
- **曲線の評価**: 区間の種類（線形・ベジェ・階段・逆階段）を、時間で区間を探して求める。ベジェは時間軸の 3 次を解いて値を求める。サンプリングは、フレームレートに依らず時刻で行う。仕様は Tsukumoe 自身の定義で、Cubism との一致は M2 で確かめる
- **プレイヤ**: レイヤごとにモーションを 1 つ持つ。フェードイン・アウトは重みで、曲線ごとの指定があればそちらを優先する。同じレイヤで新しいモーションを始めると、前のモーションはフェードアウトして重なる（クロスフェード）
- **優先度**: 待機（idle）・通常（normal）・強制（force）の 3 段階（決定済み）。同じ優先度の中は、レイヤの順に重みで混ぜる。高い優先度のモーションが再生中は、低い優先度の新しい再生は始まらない（待機モーションの自動再生が、通常のモーションを邪魔しない）。強制は、同じレイヤの再生を中断して始まる
- **表情**: 加算・乗算・上書き。フェードで出入りする。複数の表情は、起動順に重ねる
- **自動動作**: 設定（`AutoConfig`）で有効にする。まばたき（左右の目の開閉パラメータ、間隔・閉じる速さ・乱数の種）、呼吸（パラメータ、周期・振幅）。パラメータは名前で指定し、既定の名前は持たない（設定に書かせる）。乱数は種を指定できる決定的なものにする
- **1 フレームの順**: モーション → 表情 → 自動動作 → ユーザーのパラメータ設定 → ドライバ・物理・評価（既存の `Frame::advance`）。ユーザーが設定した値は、そのフレームの最後に上書きできる

## 範囲

- `tsukumoe-core`: `Frame::set_part_opacity`、`tmod` の無視可セクション（モーション・表情・ポーズ）の書き出しと検証つき読み込み、仕様書 §2 の更新
- `tsukumoe-runtime`: `Runtime`（ロード、`set_parameter`、`play_motion` / `stop` / `play_expression`、`set_auto`、`update(dt)`、描画リストの取得）
- `tsukumoe-cli`: `.tmod` の書き出しにモーション類を含める、`inspect` で件数を出す
- 範囲外: C ABI・WASM・Unity（M3-03〜05）、モーションの合成エディタ機能、リップシンク（M4）、視線追従（M4）

## 検査

- 曲線: 4 種の区間で、既知の値（端点・中点・ベジェの対称な例）と一致する。時刻の境界（区間の端、ループの継ぎ目、長さ 0）で壊れない
- プレイヤ: クロスフェードの重みが 1 になる、ループが継ぎ目で連続する、優先度とレイヤの重なりが期待値になる。フレーム分割（`dt` の刻み方）を変えても、同じ時刻の値が一致する
- 表情: 加算・乗算・上書きの式。フェードの途中の値
- 自動動作: 種が同じなら同じ結果。無効なら何も書かない
- 往復: モーション類つき `.tmod` を書き出して読み、所有版と同じ結果が出る。M3-01 の変異テストをモーション類のセクションにも広げる
- 既存: 評価器の既存テストの結果が変わらない

## 受入条件

- [x] `tsukumoe-core` の評価部分だけに依存し、編集機能を含まない（クレート依存のテストで検査）
- [x] モーションのクロスフェード・優先度・ループを扱える
- [x] まばたき・呼吸を設定で有効にできる
- [x] 表情を加算・乗算・上書きで扱える
- [x] `.tmod` にモーション・表情・ポーズを入れられ、モーション類のないローダでも読み込める
- [x] 仕様書 §2 が更新されている

## 決めたこと

- 優先度は 3 段階（待機・通常・強制）
- 自動動作のパラメータは名前で指定し、既定の名前は持たない
