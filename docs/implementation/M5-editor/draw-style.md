# M5-06d 描画まわりのキーフォーム（マスク・描画順・乗算/スクリーン色）

- REQ: REQ-EDIT-002〜007（方針は [live2d-parity.md](live2d-parity.md)）
- 状態: 計画中（利用者の確認待ち）
- 調査: コアには `SetMeshMasks`・`SetMeshDrawOrder`・キーフォームの描画順と色が既にある。不透明度と描画順は、インスペクタで編集でき、キー位置ではキーフォームに書ける（`keyed::retarget`）。足りないのは下の 3 つ

## 利用者の決定（2026-11-02）

- マスク: インスペクタにマスク欄（専用パネルは作らない）
- 描画順グループ: Part を描画順グループとして扱い、並べ替え UI を足す（形式は変えない）
- 色: インスペクタにカラー欄。キー位置ではキーフォームに書く

## 仕様案

- マスク欄（メッシュ選択時）: マスク元メッシュの一覧（名前＋外すボタン）、「マスクを追加」の選択（自分と、マスクの循環になるメッシュは出さない）、「反転」チェック。操作は `SetMeshMasks` 1 つ
- 色欄: 乗算色・スクリーン色の RGB（0〜1）を色ボタンで編集。表示値は、キーフォームつきならスライダ位置の補間値
- 新コマンド `SetMeshColors { name, multiply_color, screen_color }`（基本値）。キーフォームつきでキー上なら `keyed::retarget` がそのキーフォームの色へ書き換える（形・不透明度と同じ流儀）。キー外は拒否。モデル形式は変えない
- 並べ替え: 選択メッシュを、同じ Part の描画順で「最前面・ひとつ前・ひとつ後ろ・最背面」へ。Part 内のメッシュの描画順を振り直す `SetMeshDrawOrder` の Batch（キー位置ではキーフォームへ）。値は 0〜1000 の範囲に収める
- 取り消し: すべて 1 操作 1 ステップ
