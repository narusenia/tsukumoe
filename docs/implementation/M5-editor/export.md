# 書き出し（`tsukumoe-app`）

- REQ: REQ-EDIT-007
- 単位: M5-09
- 状態: 実装済み（実機の GUI 操作は未確認）
- 依存: M3-01
- クレート: `tsukumoe-app`（アクションとダイアログ）、`tsukumoe-format`（`runtime_bytes`。CLI の `convert` と共用）

## 範囲

- ファイル > 「ランタイム形式で書き出す...」（`file.export`）で、開いているプロジェクトを `.tmod` に書き出す。OS のファイルダイアログと、パス入力ダイアログの両方（`file.save-as` と同じ流れ）。拡張子が無ければ `.tmod` を付ける
- 書き出し前に `Model::validate()` を実行する。問題があれば一覧ダイアログを出し、ファイルは選ばせず書き出さない（`compile()` も失敗するため）
- 書き出してもプロジェクトのパス・未保存の状態は変わらない
- テクスチャは、設定で許していれば、書き出しのときにアトラスのページへまとめる（[M5-03a](texture-atlas.md)）。プロジェクトのファイルは変えない
- 範囲外: Inochi2D 形式（M6）、動画・連番画像（M5-09a）

## 受け入れ基準

- [ ] メニューの項目はプロジェクトを開いているときだけ有効
- [ ] 問題の無いモデルで `.tmod` ができ、`tsukumoe inspect x.tmod` が読め、`tsukumoe render` がエディタと同じ見た目になる
- [ ] 問題のあるモデルでは一覧ダイアログが出て、ファイルができない
- [ ] 書き出し後もタイトルの未保存表示が変わらない
