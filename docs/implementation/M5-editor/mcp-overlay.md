# MCP の重ね描き（ワイヤーフレーム・格子・ボーン・ウェイト）

- REQ: REQ-AI-002
- 単位: M5-01c
- 状態: 計画中
- 依存: M5-01b, M5-01e
- クレート: `tsukumoe-cli`（画像への重ね描き）

## 目的

リギングの確認では、テクスチャよりメッシュの形・デフォーマの格子・ボーン・ウェイトのほうが判断材料になる。これらを `render` の画像に重ねて返す。

## 範囲

- `render` / `sweep` / `render_motion` に `overlay` 引数（配列）を足す
  - `wire`: 三角形の辺
  - `vertices`: 頂点（`labels: true` で頂点番号）
  - `warp`: ワープデフォーマの格子（変形後）
  - `rotation`: 回転デフォーマの原点と向き
  - `bones`: ボーンの関節と骨
  - `weights { bone }`: 指定ボーンのウェイトをメッシュ上のヒートマップで
  - `glue`: グルーで結ばれた頂点の対
  - `names`: 各メッシュの外接矩形の中心に名前（テキストのコンテンツとして座標と名前の一覧を返す。画像には番号だけ描く）
- 重ねる対象は `only` に従う
- 範囲外: エディタのオーバーレイの見た目（色・線幅）との一致

## 方針

- エディタのオーバーレイは egui の `Painter` で描いているため流用できない。CPU で RGBA 画像に線・点・塗りを描く小さい関数を `tsukumoe-cli` に置く（依存を足さない。アンチエイリアスなし）
- 座標は描画リストの変形後の値を使い、`render` と同じ範囲・サイズで画素に写す
- 色は種類ごとに固定（背景と区別できる高彩度）。ヒートマップはエディタの `heat_color` と同じ配色にする（関数は M5-01e で UI 非依存の場所へ移す。移す前は複製せず、本単位を M5-01e の後にする）
- 番号を画像に描くための数字フォントは 5×7 のビットマップを持つ（10 字）

## 検査

- `wire` の線が、既知の三角形の辺の画素に乗る
- `weights` のヒートマップの値が、`get_element` で読んだウェイトと対応する
- 範囲外の座標で落ちない（クリップする）
- `only` で絞ったとき、ほかの要素の重ね描きが出ない

## 受入条件

- [ ] メッシュ・格子・ボーン・ウェイト・グルーを画像に重ねて受け取れる
- [ ] 重ね描きの番号から要素名・頂点番号に戻れる
