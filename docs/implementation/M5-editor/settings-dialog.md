# M5-02f 設定ダイアログ

- REQ: REQ-UI-001（編集の操作性）
- 状態: 計画中
- 依存: M5-02、M5-02c、M5-02d
- クレート: `tsukumoe-app`（ダイアログ・保存）、`tsukumoe-host`（テーマ・密度・言語の受け渡し）、`tsukumoe-core`（履歴の上限）。形式は変えない

## 目的

いま設定は、ホストのヘッダのセレクタ（テーマ・密度・言語）と、表示メニューの別々のダイアログ（パイメニュー・ドラッグ割り当て・削除の確認・ショートカット）、タブ表示の切替に散らばっている。これを 1 つの「設定」ダイアログにまとめ（A）、足りない項目を足す（B）。

## 前提（調査済み）

- テーマ・密度・言語: `tsukumoe-ui` の `Preferences`。ホストが `preferences.json`（設定フォルダ直下）に保存し、変更を即時反映する。ユーザーテーマは `themes/*.json`
- パイメニュー・ドラッグ・削除の確認・ショートカット: エディタの設定フォルダ（`editor/`）に項目ごとのファイルで保存
- 自動保存、取り消し履歴の上限、ビューポートの背景、頂点のしきい値などは設定にできない（定数、または無制限）。`History` の取り消し列は上限なし
- 表示補助（グリッド・定規・ガイド・スナップなど）は [M5-02e](live2d-parity.md) の範囲。ここでは扱わない

## A: 集約

- 表示メニューに「設定…」（アクション `view.settings`）を 1 つ置く。既定のキーは付けない（Cubism 由来のキーがないため。macOS の標準 `Cmd+,` を付けるかは確認）
- ダイアログはタブ分け。左にタブの列、右に中身
  - **一般**: 言語、テーマ、密度、パネルのタブ表示（コンパクト／フル）
  - **操作**: ドラッグ割り当て、パイメニュー、削除の確認
  - **ショートカット**: いまのショートカット一覧
  - **表示**・**編集**・**ファイル**: B の項目
- 既存の個別ダイアログ（パイ・ドラッグ・削除の確認・ショートカット）の中身をタブへ移す。表示メニューの個別項目と、既存のアクション名（`view.pie-settings` ほか）は残し、開くタブを指定して設定ダイアログを開く
- ホストのヘッダのセレクタは残す（すぐ切り替えたいため）。同じ値を設定ダイアログの「一般」でも編集でき、どちらで変えても即時反映・保存される
- 各タブに「既定に戻す」ボタン（そのタブの項目だけ戻す。確認なし。undo の対象外）

## B: 足す項目（案）

| タブ | 項目 | 既定 | 範囲 |
|---|---|---|---|
| ファイル | 自動保存の有無 | オフ | — |
| ファイル | 自動保存の間隔 | 5 分 | 1〜60 分 |
| ファイル | 設定フォルダを開く | — | ボタン |
| 編集 | 取り消し履歴の上限 | 200 ステップ | 10〜1000、0 で無制限 |
| 編集 | 近い頂点の結合のしきい値（メッシュの対角線に対する比） | 0.01 | 0.001〜0.1 |
| 編集 | 左右対称・反転コピーの組み合わせの許容（同上） | 0.02 | 0.001〜0.1 |
| 表示 | ビューポートの背景（テーマ／白／黒／市松） | テーマ | — |
| 表示 | 頂点・辺をつかむ半径（画面の点） | 8 / 5 | 4〜16 |

- 自動保存: 間隔ごとに、未保存の変更があるときだけ、プロジェクトの横の `<名前>.autosave` に書く。本体のファイルは上書きしない。起動時の復元は範囲外
- 取り消し履歴の上限: 超えた分は古い順に捨てる。やり直しの列は変えない
- しきい値・半径: いま定数の `WELD_NEAR_RATIO`、`MIRROR_TOLERANCE`（`mirror::PAIR_TOLERANCE`）、`VERTEX_RADIUS`、`EDGE_RADIUS` を設定値に置き換える。範囲外の値は範囲に丸める
- 範囲外: ビューポートのグリッド・定規・ガイド・スナップ（M5-02e）、キー割り当てのプリセット追加

## 保存

- B の項目は、エディタの設定フォルダの `editor/options.json` に 1 つのファイルで保存する。項目が無い・壊れているときは既定値（`serde(default)`）
- テーマ・密度・言語は、これまでどおり `preferences.json`。設定ダイアログで変えた値は、ホストが受け取って反映・保存する（ホストのセレクタと同じ経路）
- 画面状態（開いているタブ）は保存しない（ADR-0019）

## 段階

1. 設定の型と保存（`options.json`）、既定値、範囲の丸め、テスト
2. 設定ダイアログの骨格と、一般・操作・ショートカットのタブ（既存ダイアログを移す）、メニュー・パレット・アクション
3. B: 履歴の上限（core）、しきい値・半径の置き換え、背景
4. B: 自動保存

各段階の終わりに、変更範囲のテスト・clippy・スナップショット（ダイアログの見た目はライト・ダーク）を確かめる。

## 確認したい点

- B の項目と既定値はこれでよいか（足す・削る）
- `Cmd+,`（macOS）／`Ctrl+,` を設定ダイアログの既定のキーにしてよいか
- 自動保存は「横に `.autosave`」でよいか（本体を上書きする方式にはしない）
