# M5-05a ボーンとウェイトペイント

- REQ: REQ-EDIT-003（後半）、REQ-CORE-003
- 状態: 実装済み・実機未確認
- 依存: M5-05、M5-06a（キーフォーム）
- クレート: `tsukumoe-core`（コマンド・検査）、`tsukumoe-cli`、`tsukumoe-app`（ツール・パネル）。形式（`.tproj`、`.tmod`）と評価は変えない

## 前提（調査済み）

- モデルに `Bone { parent, base: BoneTransform, keyforms }` と、メッシュの `influences: Vec<VertexInfluences>`（頂点ごとに最大 4 ボーンと重み）がある。評価（`eval.rs`）、`.tmod`、`.tproj` の DTO は既にあった
- ボーンの座標は、メッシュの親デフォーマの局所空間（ADR-0021）。1 本のボーンの木を使うメッシュは、同じ親デフォーマに掛かっていなければならない。実装前はこれを `compile` だけが調べていた
- 重みの合計が 1 に足りない分は、元の頂点がそのまま残る。1 を超えると 1 に縮める（評価の規則）
- 編集コマンドはなく、ボーンのキーフォームはバインドの操作から外れていた（`used_by_others` で共有を拒否）

## 決めたこと

- **コマンド**（`command/bone.rs`。すべて 1 ステップで取り消せる）
  - `AddBone { name, parent, base }`、`RemoveBone`、`RenameBone`、`SetBoneParent`
  - `SetBoneBase { name, base }`（キーフォームのないボーンの基本値。キーフォーム付きは拒否）、`SetBoneKeyform { name, key, base }`（キー位置の変換）
  - `SetMeshInfluences { name, influences }`: 頂点ごとに最大 4 つの `{ bone, weight }`。頂点数と合わない、5 本以上、同じボーンの重複、負・有限でない重みは拒否。空の一覧でスキンを外す
  - `BoneBase { translation, rotation_degrees, scale }`。拡大が 0（逆変換できない）は拒否
- **検査**（`validate`）: ボーンの木を使うメッシュの親デフォーマが揃っているか。コマンドが壊すなら拒否される。`compile` の同じ検査と `CompileError::BoneSpaceMismatch` は、到達しなくなったので消した
- **キーフォーム**: `ElementRef::Bone` を足し、バインド・解除・キーの追加削除・軸順・軸の付け替えに乗せた（`used_by_others` は廃止）。補間は `Blend for BoneTransform`（移動・角度・拡大を線形に混ぜる）
- **ボーンパネル**（`panels/bones.rs`）: ボーンを親ごとに入れ子で並べる。追加（選択中のボーンの子）、削除、名前、親（自分と子孫は選べない）、移動 X/Y、回転、拡大 X/Y。キーフォーム付きのボーンは、スライダがキーの上にあるときだけ編集できる（外なら拒否して知らせる）
- **ボーンツール**（`bone_tool.rs`、キー `B`）。2 つのモード
  - ボーン: ビューポートの空きをクリックで、選択中のボーンの子（なければ根）を置く。関節をクリックで選ぶ。関節のドラッグで移動する（離したとき 1 コマンド）。位置はメッシュの親デフォーマの空間で表示し、置く・動かすときは逆変換する
  - ウェイト: ツリーで選んだメッシュ（最後に選んだもの）と、選んだボーンの重みを、ブラシで塗る。頂点を重みの色（青 0 → 赤 1）で示す。ブラシは加算・減算・ぼかし（近傍の平均へ寄せる）、半径（画面の点）と強さ。ストロークの間は作業用の重みで見せ、離したとき `SetMeshInfluences` を 1 つ送る。加算で他のボーンの重みの合計が 1 を超えるときは、他を縮める。5 本目は、塗っているボーン以外で最も弱いものが落ちる
  - ウェイトのモードで関節をクリックすると、塗るボーンが変わる
- **保存**: 既存の形式のまま。パネルとツールの状態は保存しない

## 既知の割り切り

- ボーンの回転・拡大は、パネルの数値で編集する（ビューポートのハンドルはない）
- ストロークの途中は、スキニングによるメッシュの変形を出さない（重みの色だけ）。離すと変形に反映される
- 自動ウェイト（骨からの距離）は作らない。ブラシで塗る
- ボーンの鏡映コピー・複製はない

## 検証

- `tsukumoe-core`: 各コマンドの適用・Undo・不正値の拒否、使われているボーン・親は消せないこと、親デフォーマの異なるメッシュで同じ木を使えないこと、ボーンのキーフォームで頂点が動くこと
- `tsukumoe-app`: 関節の位置と選択、置く・動かす、キー位置でのコマンドの選び分け、ブラシ 3 種と 4 本の上限、ストロークから 1 コマンド、パネルの kittest、スナップショット（パネルとウェイトの重ね描き）
- 実機の GUI 操作は `gui-checklist.md`
