# M5-05c-1 ワープのベジェ補間

- REQ: REQ-EDIT-003（方針は [live2d-parity.md](live2d-parity.md)）
- 状態: 実装済み・実機未確認
- 形式の変更: `.tmod` に任意セクション `warp_bezier`（0x9B）を足した（マイナー追加。知らない読み手は双線形で評価）。`model.json` には既に `bezier` がある

## 利用者の決定（2026-11-02）

- 曲面の定義は、格子点を通る Catmull-Rom 風の 3 次曲面（Cubism の内部式は調べない。ADR-0016）
- 05c は「05c-1 ベジェ」「05c-2 糊」に分ける。糊は計画書を別に書いて確認する

## 仕様

- 評価: [evaluation.md](../../specifications/evaluation.md) のワープの節。双 3 次 Catmull-Rom。格子の外は端の 2 点を通る直線で延長して補う。等間隔の格子では双線形と一致する
- 形式: `.tmod` の `warp_bezier`（ファイル形式 2.3）。ワープが 1 つも使わないファイルは変わらない
- コマンド `SetWarpBezier { name, bezier }`。ワープを選ぶとインスペクタに「なめらかな曲面（ベジェ）」のチェックボックス。取り消しは 1 ステップ

## 既知の割り切り

- ビューポートの格子の線は、曲面でなく制御点どうしの直線のまま（メッシュは曲面で動く）
- 子ワープの制御点の変換にも親の曲面を使う。その結果は親の変形後の点で、曲面の近似にとどまる
- 格子の外の延長は、直線の延長なので端で傾きが連続しない場合がある
