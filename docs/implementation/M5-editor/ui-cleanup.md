# M5-02g エディタ UI の見直し

- REQ: REQ-UI-001（編集の操作性）
- 状態: 着手中（①②⑤ 実装済み。②の作成後 +/− キー・ホイール、⑤の ai_diff 除外は未。③ から）
- 依存: M5-02f
- クレート: `tsukumoe-app`（パネル・オーバーレイ・文言）、`tsukumoe-ui`（部品）、`tsukumoe-i18n`（ja / en の両方）。形式・core は変えない

## 目的

画面が散らかって見えるので、見た目・文言・設計・経路を整理し、作業が速くなる操作を足す。1 つの計画を ①〜⑥ の塊に分け、順に入れる。

## 監査の所見

### 見た目・配置

| 重要度 | 所見 | 場所 |
|---|---|---|
| 高 | ヒント・キー表示・ソロバッジ・ツールバーが固定オフセットで重なる。バッジとヒントは両方 (8,8)。ヒントは折り返さず、狭いと右上の箱に潜る | `viewport.rs`、`mesh_overlay.rs`、`toolbar.rs`（`TOP`）、`proportional_overlay.rs` |
| 高 | グリッド入力の順序が逆。メッシュは「列 × 行」、ワープとインスペクタは「行 × 列」 | `mesh_overlay.rs`、`deformer_overlay.rs` |
| 高 | 輪郭の設定が名前なしの数字 4 個（しきい値・間引き・オフセット・間隔） | `mesh_overlay.rs` |
| 中 | 矢印アイコンが 2 つの意味で重複（ツールバーの選択ツール、メッシュ箱の選択サブモード）。`Grid` はデフォーマ・タブ・距離種別、`Image` はメッシュツールとビューポートタブ | 各所 |

### 文言

- 古い用語: パネル名は「パーツ / デフォーマ」だが、文言が「ツリー」のまま（`inspector-none`、`mesh-edit-pick`、`deformer-pick`）
- Part が英語のまま（`tree-kind-part`、`tree-set-part`、`confirm-kind-tree`）
- 揺れ: 束縛 / バインド、キー / キーフォーム、糊 / グルー
- 文体の混在: 体言止めに「〜ます」（`mesh-edit-pen-hint`、`drag-hint`）
- 長い・読みにくい: `deformer-hint`、`mesh-edit-hint`、`tree-rename-external`、`deformer-has-keyforms`、「空きは頂点を足してつなぐ」
- ヒントの生の「Mod」を、利用者のキー名（⌘ / Ctrl）に差し替える
- `drag-hint` のパン操作の説明はビューポート側の話

### 設計・経路

- オーバーレイの枠が 4 か所で重複（toolbar、メッシュ、デフォーマ、比例編集）
- 専用 UI が足りない: 輪郭メッシュのプレビュー、グリッド数の決め方、ブレンドモード
- 経路のないデータ: `BlendMode`（コマンドはあるがインスペクタにない）、`SetMeshUvs`。ボーン・物理・モーション・表情は M5-05a / 07 / 08（未着手）
- Animation ワークスペースは Modeling と同じパネルで、アニメ用の道具がない

## 決定事項（利用者に確認済み）

- ヒントとキー表示は**左下に折り返して表示**。左上はツールバー、右上は箱の積み、上中央はソロバッジ
- パネルのタブは**アイコンと名前**を既定にする（設定でアイコンのみに切り替え可能）
- 用語は **Cubism の慣習に寄せる**: パーツ、バインド、キーフォーム（パラメータ上の点はキー）、グルーは「グルー」。「ツリー」は消す
- Animation ワークスペースは **M5-08 まで非表示**（タブとアニメーションのパネルも）
- グリッド数は**自動推定 + チップ + 作成後の +/− キーかホイール**。数値入力は「その他」
- ツールバーは**ツールの下にフライアウト（設定）と主要アクション**。右上の箱は廃止
- ホバーは**ビューポートの強調 + 遅延カード**（0.5 秒でサムネイル・頂点数・バインド先・マスク・描画順）。Part は薄いバウンディングボックスを出す
- ツリー行の常時表示は**メッシュの小サムネイルとバインド済みバッジ**
- 右クリックは**ビューポート（選択ツール）・ツリー行・パラメータ行・メッシュ / デフォーマツール**を充実させる。ショートカット表示・アイコン・区切り・サブメニュー
- 細かい UX: ビューポート↔ツリーのホバー連動、ダブルクリックと F2 で名前変更、数値欄の統一（ダブルクリックで既定値、Shift で微調整、Esc で取消）、直前コマンドの繰り返し（Shift+R）とパレットの最近使った項目
- 空状態の案内の代わりに**スプラッシュスクリーン**（新規 / 開く / PSD から新規 + 最近のプロジェクト）。「ショートカットの早見」「PSD のドロップ」は入れない
- パイメニューの設定画面を、**実際のパイの形（放射状）**に作り直す

## 着手順

各塊は、実装 → 変更したクレートの fmt・clippy・テスト → 変更した画面のスナップショット更新 → コミット、で入れる。

### ① オーバーレイ部品と配置

- 状態: 実装済み
- `panels/overlay.rs`: `boxed`（枠）、`options_stack`（右上の積み）、`tools`（左上）、`status`（上中央）、`help`（左下・折り返し・クリックを通す）
- toolbar・メッシュ・デフォーマ・比例編集の枠を共有部品へ。`TOP` と固定オフセットを消す
- ソロバッジを `status` へ

### ② ツールバーとグリッド

- ツールバーを、ツールの下のフライアウト + 主要アクション（メッシュ: グリッドを敷く・輪郭から作る・結合。デフォーマ: ワープを作る・回転を作る）に。キーバッジ常時表示
- 右上の箱を廃止し、設定をフライアウトへ。比例編集のオンオフは 1 か所に
- 選択サブモードのアイコンをツールバーの矢印と区別する。左右対称をアイコンに
- グリッド: 行 × 列に統一。チップ（2×2 / 4×4 / 8×8 / 自動）、前回値の記憶、作成後の +/− とホイール。「自動」は対象の縦横比とサイズから推定する（ロジックは `tsukumoe-core` の `mesh_edit` ではなくアプリ側に置く）
- 輪郭: ラベル付きの行にする。プレビューのライブ更新は別途検討（重ければ後回し）

### ③ ツリー行とホバー

- 行にメッシュの小サムネイル（テクスチャの切り出し、16px）とバインド済みバッジ
- ホバー: ビューポートの要素を縁取り強調（Part は薄いバウンディングボックス）。0.5 秒でカード（サムネイル・頂点数・バインド先・マスク・描画順）
- ビューポートで要素に乗せると、ツリーの行も光る（逆方向）
- 「Parts の隣のグリッドアイコン」をやめ、タブをアイコン + 名前に

### ④ 右クリック

- 選択ツールのビューポートにメニューを新設（隠す・ソロ・名前を変更・複製・親を選ぶ・描画順・デフォーマで囲む）
- ツリー行: ショートカット表示・アイコン・区切り・「配下を…」のサブメニュー
- パラメータ行: リセット・キーの追加・バインド・複製・グループへ移動
- メッシュ / デフォーマツール: 14 項目を頂点・辺・メッシュ全体に分け、区切りとサブメニューで整理
- メニューの描画を共有部品にする（`menu_ui` を拡張）

### ⑤ 文言と用語

- ja / en の両方を直す。`tsukumoe-i18n` に両言語のキー対応のテストがあるので通す
- 用語は決定事項どおり。長いヒントは短くし、「Mod」は利用者のキー名に差し替える
- `section_header` の `to_uppercase()` をやめる
- 文体は、既存の体言止めに揃える。説明しすぎず、読み手が今していることに関係する分だけ書く
- `ai_diff` パネルは中身ができるまで既定配置から外す（見送り: レイアウトは全パネルを必ず持つ設計。「閉じたパネル」の扱いを決めてから）

### ⑥ 細かい UX・スプラッシュ・パイ

- ビューポート↔ツリーのホバー連動、ダブルクリック / F2 で名前変更
- 数値欄の統一（ダブルクリックで既定値、Shift で微調整、Esc で取消）。スライダー・ドラッグ値で同じ操作に
- 直前コマンドの繰り返し（Shift+R）、パレットの最近使った項目
- スプラッシュ: プロジェクトなしのとき、ビューポートに新規 / 開く / PSD から新規と最近のプロジェクト
- パイメニュー設定を放射状の見た目に
- キーパネル: Bind を先頭に、アイコン化、ミラーを折りたたみに、中心線欄にラベル
- Animation ワークスペースの非表示、ブレンドモードの選択（インスペクタ）

## 検証

- 変更したクレートの fmt・clippy・テストだけ回す（フル一式は節目だけ）
- 見た目が変わる塊は `UPDATE_SNAPSHOTS=1 cargo test -p tsukumoe-app --test snapshots <name>` で更新し、`.diff.png` と `.new.png` を消す
- 実機確認の項目は `gui-checklist.md` に足す（`[x]` は利用者が付ける）
