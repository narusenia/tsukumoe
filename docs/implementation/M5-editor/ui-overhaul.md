# M5-02h エディタ UI の全面見直し（変更点）

- REQ: REQ-UI-001（編集の操作性）
- 状態: 実装済み（実機の GUI 操作は未確認）。手順は [gui-checklist.md](gui-checklist.md) の「M5-02h」
- 依存: M5-02g
- クレート: `tsukumoe-ui`（部品）、`tsukumoe-app`（パネル）、`tsukumoe-i18n`（ja / en）

## 見つけた問題と直したこと

| 問題 | 直し方 |
|---|---|
| 欄の並びがパネルごとに違う（表のもの、横並びのもの、ラベルなし）。ラベルと欄の開始位置が揃わない | 共通の `form_row`（ラベル列はパネル幅に追従、欄は残りの幅）。インスペクタ・設定ダイアログ・モデル設定・ボーン・キー・物理・表情が同じ部品を使う |
| 見出しが小さく薄く、区切りがない | `section_header` を通常の濃さと罫線つきに。パネル先頭では上の余白を出さない |
| 折りたたみが egui 標準の三角で、他の部品と見た目が違う | `collapsible`（シェブロン + ホバー）。キーの設定・ミラー・物理の詳細・パラメータのグループが使う |
| パラメータ行が狭いと名前が `ParamA…` に切れ、スライダーが細い | 幅 300 未満は 2 段（名前とボタン / スライダーと数値）。広いときは従来の 1 段 |
| タイムラインと表情の数値欄にラベルがない（3.00 と 30.00 が何か分からない） | 長さ・fps・フェードイン・フェードアウト・重みにラベルを付けた |
| インスペクタの情報が少ない | メッシュに所属パーツ・親デフォーマ・バインド先を追加。ブレンドモードと重なりの行をフォームに揃えた |
| 物理のスライダーのラベルが揃っていない | 共通フォーム行に |
| 右ストリップとツールバーで、アイコンが重複（物理とボーンがどちらもリンク、キーとデフォーマがどちらもグリッド） | ボーン・アクティビティ・ダイヤ・スマイルを追加し、ボーンツール・ボーン・物理・キー・表情に割り当てた |
| ツールバーでツールと比例編集のオプションが同列 | 罫線で分けた |
| ダイアログのボタンが左寄せで、パスが空でも OK が押せる | 右寄せ（OK が右端）。空のとき OK は無効 |
| 無効なアイコンボタンはホバーしても名前が出ない | 無効時もツールチップを出す。追加の「+」は枠つき（Secondary）に |
| ステータスバーが名前だけ | 選択中の要素名（複数は件数）を右に出す |
| 日本語で英単語・数字の前後に半角スペース（`PSD を`、`2 つ`、`{ $count } 件`） | 一括で除去。プレースホルダの前後も詰めた |
| 説明文が UI に残っている（設定の注記、パイ・ショートカット・ドラッグの説明、空状態の長い案内） | 削除または 1 語に。操作のヒント行（ビューポートの左下）は短くして残した |

## 部品

- `tsukumoe_ui::form_row(ui, name, add)`: ラベル列は `clamp(幅 × 0.38, 64, 200)`。欄の中の `select` は残りの幅に広がる
- `tsukumoe_ui::collapsible(ui, id, title, default_open, add) -> (Response, Option<R>)`
- `section_header`: 罫線つき
- ショーケース（`tsukumoe-ui`）に両方を追加。スナップショットは更新済み

## 判断したこと

- ライブラリは足さない。egui の部品の上に共通部品を置く方が保守しやすい
- Live2D の用語・並びは変えない（パーツ、パラメータ、キーフォーム、バインド、ミラー）。変えたのは見た目と欄の整列だけ
- パネルの統合・分割は今回しない。パネル配置はユーザーの保存済みレイアウトに載っていて、既定を動かすと既存の配置が崩れる
- 説明文は消した。初心者向けの案内は、ラベルとホバーの名前、ビューポート左下の操作行で足りる

## 作らない / 残すもの

- ホバーカード・右クリックメニューの再設計: M5-02g で作ったものを変えていない
- ビューポート本体（GPU の描画）は変えていない。ヘッドレスのスナップショットでは描画されない
