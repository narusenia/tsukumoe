# M5-02e 表示補助

- REQ: REQ-UI-001（編集の操作性）。方針は [live2d-parity.md](live2d-parity.md)
- 状態: 実装済み・実機未確認（キャンバスの回転と複数ビューは作らないと決めた。下の「作らないもの」）
- 依存: M5-02
- クレート: `tsukumoe-app`（状態・描画・保存）、`tsukumoe-i18n`（ja / en）。モデル・形式・core は変えない

## 決めたこと

- **状態**（`view_aids.rs`、ビュー状態。ADR-0019 のとおりモデルにも履歴にも入れない）: グリッド（表示・間隔）、定規、スナップ、情報、ガイド（X・Y）、参照画像の設定。間隔 0 は「定規と同じ丸い間隔を、今のズームで自動に」
- **保存**: プロジェクトの `editor/view.json`（設定）と `editor/reference`（参照画像の PNG）。パラメータのペアと同じ置き場。既定値のままなら書かない。古いプロジェクトは何も無いので既定
- **表示の入口**: ビューポート右上の目のアイコンで開く箱（グリッド / 定規 / スナップ / 情報 / 間隔 / ガイドを消す / 参照画像）。メニューやアクションは足さない
- **グリッド**: 間隔ごとの線。1 辺に最大 200 本まで描く（極端な拡大縮小で重くならない）
- **定規**: 上と左。丸い間隔で目盛りと数字（間隔に合う小数桁）。ポインタの位置に印
- **ガイド**: 定規からドラッグで作る（上の定規 → 水平のガイド、左 → 垂直）。ガイドのドラッグで動かし、定規の上で離すと消える。スナップが入っていれば、置く位置もグリッドに乗る
- **スナップ**: ポインタの位置ではなく、動かすときの移動量をグリッドの間隔の整数倍にそろえる（メッシュの頂点・ワープの点・回転の原点・ボーンの関節のドラッグ）。範囲選択の箱は対象外。新しいボーンを置く位置は、近いガイド（6 点以内）か、グリッドに乗る。拾う（選ぶ）判定はスナップしない
- **参照画像**: PNG のみ（プロジェクトのテクスチャと同じ）。読み込んでプロジェクトに入れる（持ち運べる）。初めはモデルの範囲の幅に合わせ、拡大率・位置・不透明度・表示のオンオフを箱で変える。外すとプロジェクトからも消える。モデルの後ろに描く
- **情報**: メッシュ・頂点・三角形の数、ズーム、ポインタのモデル座標を、右下に出す

## 作らないもの

- **キャンバスの回転**: ビューの矩形（`Mapper`）が軸に平行なことを、全ツールの当たり判定と重ね描きが前提にしている（約 40 か所）。回転を入れるには、描画（`tsukumoe-gpu`）、`Mapper`、すべてのツールを作り直す必要があり、描かないモデリング（Tsukumoe はお絵描きではない）での利点に見合わない。必要になったら、まず `Mapper` を一般のアフィン変換にする単位として起こす
- **複数ビュー**: ビューポートの状態（カメラ・ソロ・ツール）が 1 つのビューを前提にしている。比較は、ソロとワークスペースの切り替えと参照画像で足りる

## 検証

- `view_aids`: 丸い間隔・目盛り・スナップ（グリッド・ガイド・移動量）・設定の往復と、読めない設定が既定になること
- `project`: 設定と参照画像の保存・削除（既定なら書かない）
- `editor`: 参照画像の読み込み（壊れた PNG は拒否）・外す・設定が変わったときだけプロジェクトに書くこと
- 箱の kittest（スイッチ・ガイドを消す・参照画像のボタン・開閉）、スナップショット（グリッド・ガイド・定規・箱）
- 実機の GUI 操作は `gui-checklist.md`
