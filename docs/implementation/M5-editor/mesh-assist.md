# M5-04c 作成補助（左右対称編集・投げ縄選択・頂点の結合）

- REQ: REQ-EDIT-002（方針は [live2d-parity.md](live2d-parity.md)）
- 状態: 実装済み・実機未確認
- モデル形式の変更: なし。コマンドは既存の `SetMeshPositions`・`SetMeshGeometry` だけ

## 利用者の決定（2026-11-02）

- 対称の軸: モデル中心を自動（`mirror::center`。06c の反転コピーと同じ軸。パラメータパネルの「反転の中心線 x」入力で上書き）
- 対応づけ: 同一メッシュ内の頂点どうし。鏡像の位置の最寄りの頂点を、メッシュ幅の 2% 以内で対にする。左右の別メッシュの連動は作らない
- 投げ縄: メッシュ編集の頂点選択と、選択ツールのメッシュ選択の両方
- 結合: 選択頂点を重心へ 1 点に結合、近接頂点の一括結合の両方

## 仕様

- 左右対称編集: メッシュツールのオプション欄の「左右対称」ボタン、またはアクション `mesh.symmetry`（`Y`）で切り替える。オンの間、頂点の移動（プロポーショナル編集つきも）で、動かした頂点の鏡像の頂点が、軸の反対側の鏡像の位置へ動く。鏡像のない頂点・軸上の頂点は対象外。軸は黄の縦線で出る。設定は保存しない
- 投げ縄（メッシュツール）: Mod + 空きをドラッグで自由曲線。内側の頂点を選ぶ（Shift で追加）
- 投げ縄（選択ツール）: 空きをドラッグで自由曲線。重心が内側のメッシュを選ぶ（Shift で追加）。描画されているメッシュだけが対象
- 頂点の結合 `mesh.weld`（`J`）: 選択した頂点（2 つ以上）を、位置と UV の平均の 1 点にする。つぶれた三角形は消え、使われない頂点は除く。全部つぶれるなら拒否
- 近接結合 `mesh.weld-near`（`Shift+J`）: メッシュの対角線の 1% 以内にある頂点を、つながりで連鎖させて 1 点にまとめる。該当がなければ「変更なし」
- コアに `mesh_edit::weld`・`weld_near` を追加

## 既知の割り切り

- 結合は面の向き・折り返しを検査しない（折れたら undo）。必要になったら検査を足す
- 軸のすぐ近く（幅の 2% 以内）の頂点は、鏡像の対を軸上の別の頂点と取り違えることがある
- 左右対称編集はメッシュの頂点だけ。ワープ・回転の対称編集は別単位
