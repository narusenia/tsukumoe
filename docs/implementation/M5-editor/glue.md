# M5-05c-2 糊（グルー）の作成・編集

- REQ: REQ-EDIT-003（方針は [live2d-parity.md](live2d-parity.md)）
- 状態: 実装済み・実機未確認
- 依存: M5-05c-1、M5-06a〜c（キーフォーム）
- クレート: `tsukumoe-core`（コマンド）、`tsukumoe-cli`、`tsukumoe-app`（ツール・インスペクタ）。形式と評価は変えない

## 前提（調査済み）

- モデル `Glue { mesh_a, mesh_b, nodes: Vec<GlueNode{index_a, index_b, weight}>, intensity, keyforms: Option<KeyformGrid<f32>> }`、`.tmod`（0x23〜0x25）、`.tsukumoe` の DTO は既にある
- 評価（`eval.rs`）は糊を反映済み。各節点で 2 頂点を `weight` で決まる合流点へ `intensity` の割合だけ寄せる。キーフォームがあれば `intensity` を補間する
- 編集コマンドはない。メッシュの頂点数を変える操作は、糊が使うメッシュでは既に拒否される
- 実装前は、キーフォームの共有・バインドの操作（06a）がメッシュ・ワープ・回転だけを対象にしていた

## 決めたこと（実装済み）

- **コマンド**（`command.rs`）
  - `AddGlue { name, mesh_a, mesh_b, nodes, intensity }`。同じメッシュどうし、範囲外の頂点番号、有限でない強さ・重みは拒否。取り消しは 1 ステップ
  - `RemoveGlue`、`RenameGlue`、`SetGlueIntensity`（キーフォームなしの基本値。キーフォーム付きは拒否）
  - `SetGlueKeyform { name, key, intensity }`（キー位置の強さ）。節点の差し替え・重みの編集は作らない（削除して作り直す）
- **キーフォーム**: `ElementRef::Glue` を足し、糊を 06a のバインド・解除・キーの追加削除・軸順に乗せた。同じ軸・キーのバインドは他の要素と共有する。強さは `Blend for f32` で補間
- **作り方**: メッシュツールで頂点を選び `mesh.glue-source`（片側を指定）→ 別のメッシュで頂点を選び `mesh.glue`。描画位置の近い順に 1 対 1 で組み、重み 0.5・強さ 1.0 で作って選択する。パレットから呼ぶ（既定のキーはなし。Cubism 由来のキーがないため）
- **ツリー**: デフォーマパネルの末尾に糊の行。選択・名前変更・削除ができる。メッシュを消すとそのメッシュの糊も同じ `Batch` で先に消える。複製は不可
- **インスペクタ**: 2 メッシュの名前・節点数・強さ。キーフォーム付きの糊は、キー位置でだけ強さを編集する（キー外は拒否）
- **ビューポート**: 選択中の糊の節点を、描画位置の 2 点を結ぶ線で示す（メッシュ A 側に輪、B 側に点）。強さ 1.0 では 2 点が重なり、線は点になる
- 形式（`.tmod`、`.tsukumoe`）と評価は変えていない

## 既知の割り切り

- `mesh.glue-source` で指定した頂点は、画面に出ない（指定済みかどうかが見えない）
- 組み合わせは近い順の貪欲法。選択数が違うと、多い側の遠い頂点は組まれない
- 糊を使うメッシュの頂点数を変える操作は、これまでどおり拒否

## 範囲外

- 節点ごとの重みの編集、節点の追加・削除
- 頂点の自動対応づけ（距離しきい値で自動で組む）
- 糊を使うメッシュの頂点数を変える操作の解禁
- 指定した頂点のビューポート表示
