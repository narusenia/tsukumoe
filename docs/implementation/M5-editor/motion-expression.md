# モーションと表情の編集（`tsukumoe-core` / `tsukumoe-app`）

- REQ: REQ-EDIT-006（モーションと表情の編集）。リップシンクの取り込みは REQ-AI-008 の「音声ファイルから motion を生成できる」の出力を受ける側
- 単位: M5-08（①モーションのデータ編集とタイムライン、②カーブエディタ、③表情）。① → ② → ③ の順に、1 つずつ実装して実機で確かめる
- 状態: ①②③ 実装済み（実機の GUI 操作は未確認）
- 依存: M5-02、M5-06a（パラメータの参照）
- クレート: `tsukumoe-core`（コマンド。評価は変えない）、`tsukumoe-app`（タイムラインとカーブエディタのパネル、再生の操作）、`tsukumoe-format`（取り込みの読み出しが足りないとき）。新しい依存クレートは足さない

## 目的

モーション（パラメータ・パーツ不透明度の時間カーブ）と表情（パラメータの差分セット）を、エディタで作って編集し、ビューポートで再生して確かめる。完了すると Animation ワークスペースを `Workspace::SHOWN` に加える。

## 前提（現状）

- 編集モデルは `Model::motions()` / `expressions()`（`Table<Motion>` / `Table<Expression>`）を持つ。型は `tsukumoe-core/src/playback.rs`（`Motion` `Curve` `Segment` `Expression`）。`.tmod` では `tmod/playback.rs` の平坦な配列（`MotionDef` `CurveDef` `SegmentDef`）に変わる
- `Segment` は `Linear` / `Bezier`（制御点 2 + 終点）/ `Stepped` / `InverseStepped`。要件の 4 種はすでにデータにある。足りないのは編集コマンドと UI
- モーション・表情を作る・変える `Command` は無い（`command.rs` に該当なし）。`Model::validate()` はモーション・表情が消えたパラメータを指していないかを検査する（`validate.rs`）。パラメータの削除は、モーションが名指ししていれば失敗する
- 再生は `tsukumoe-runtime` の `MotionPlayer`（レイヤー、優先度、クロスフェード）と `ExpressionPlayer`（`ExpressionBlend` の加算・乗算・上書き）。曲線の評価は `curve::sample`。エディタは `Scene.frame`（`Frame::advance`）で評価している
- CLI の `tsukumoe lipsync` は WAV から `motions/<name>.json`（`MotionFile`）を書く。`tsukumoe-app` は `tsukumoe-ai` に依存していない
- Animation ワークスペースのレイアウト（`layouts/*_animation.json`）はあるが、タイムラインのパネルは無い

## M5-08 ①: モーションのデータ編集とタイムライン

- **コマンド**（すべて `Command`。Undo 1 回で戻る）
  - モーションの追加・削除・名前変更、長さ・fps・ループ・フェードの変更
  - カーブの追加（パラメータまたはパーツ不透明度を対象に）・削除、カーブごとのフェードの上書き
  - キー（セグメントの終点）の追加・削除・時間と値の移動。時間は前後のキーを越えない
  - 追加するキーの値は、その時間のカーブの値で埋める（追加しても形が変わらない）
- **タイムライン**（パネル `timeline`）
  - 左にカーブの一覧（対象の名前、表示切替）、右に時間軸とキーの点。再生ヘッド、ズーム、スクロール
  - 再生・停止・ループ、再生ヘッドのドラッグ（スクラブ）。再生は `MotionPlayer` を使い、ビューポートの絵が動く。画面状態（再生ヘッド・ズーム）は編集モデルに入れない（ADR-0019）
  - 「現在値でキーを打つ」: フォーカス中のパラメータの現在のスライダ値を、再生ヘッドの位置のキーにする（カーブが無ければ作る）。自動キーは入れない（「決めたこと」）
- **リップシンクの取り込み**: `tsukumoe lipsync` が書いた `motions/<name>.json`（`MotionFile`）を、ファイル選択で読み込んで新しいモーションにする。名前の衝突は末尾に番号。モデルに無いパラメータ名のカーブは読み込まず、数を知らせる
- 範囲外: 音声ファイルからの解析そのもの（CLI の `lipsync`。エディタに `tsukumoe-ai` を足すかは「決めたこと」）、モーションのレイヤー合成の編集、`motion3.json` の直接の読み書き（COMPAT 側）

## M5-08 ②: カーブエディタ

- 選んだカーブを、時間 × 値の平面で編集する（タイムラインの下、または別タブ）
- セグメントの種別を切り替える: 線形・ベジェ・ステップ・逆ステップ。種別を変えても終点は動かさない。ベジェに変えたときの制御点は、前後の 1/3 の位置の直線上に置く（見た目が変わらない）
- ベジェの制御点をドラッグ。制御点の時間はセグメントの両端の間に収める（`curve::sample` が単調な時間を前提にするため。実装時に `curve.rs` で確かめる）
- 複数のキーの選択、移動、値の揃え。ズームは時間・値で別々
- 受け入れの核: 4 種類すべてを作る・切り替える・保存して開き直しても同じ形で、`.tmod` に書いて `MotionPlayer` で再生しても同じ値になる

## M5-08 ③: 表情

- **コマンド**: 表情の追加・削除・名前変更、フェードの変更、項目（パラメータ + `ExpressionBlend` + 値）の追加・削除・変更
- **UI**（パネル `expressions`）: 表情の一覧と、選んだ表情の項目表。項目ごとにパラメータ・合成方法（加算 / 乗算 / 上書き）・値。「今のパラメータの値から取り込む」ボタンで、既定値と違うパラメータを項目にする
- **確認**: 表情のボタンでビューポートに適用し、重みを 0〜1 のスライダで見られる（`ExpressionPlayer` を使う）
- 範囲外: ポーズ（`Pose`）の編集（要件にない）

## 決めたこと（①の実装）

- 再生は `tsukumoe-runtime` の `MotionPlayer` を使わず、`Curve::value_at` でパラメータ値を求めてビューの値（`ViewState`）に入れる。アプリに `tsukumoe-runtime` を足さないため。レイヤー合成・フェードは再生に反映されない。パーツ不透明度のカーブは、レーンには出るがビューポートには反映されない
- カーブの編集は `SetMotionCurve`（全置換）1 種に集約し、キーの追加・削除・移動は `Curve` の関数（`insert_key` / `remove_key` / `move_key`）で新しいキー列を作る。ドラッグ・欄の入力は作業用の複製に溜め、ポインタとキーボードが離れたときに 1 回だけ送る（Undo 1 回）
- リップシンクは CLI の `tsukumoe lipsync` が書く `motions/<name>.json` を読み込む（`motion_import.rs`）。エディタに `tsukumoe-ai` は足さない。モデルに無いパラメータ・パーツのカーブと、同じ対象の 2 本目は読み込まず、数をトーストで知らせる。名前の衝突は末尾に番号
- 自動キーは入れない（スライダ操作の検出がパネルの外にあり、規模が合わない）
- Animation ワークスペースを `Workspace::SHOWN` に加えた。`timeline` パネルは 4 つのプリセットすべてに置く（Animation は下段の先頭タブ、Modeling は履歴の隣）
- 範囲外のまま: モーション名の変更 UI（コマンド `RenameMotion` はある）、カーブごとのフェードの UI（コマンド `SetMotionCurveFade` はある）

## 決めたこと（②③の実装）

- **②の置き場**: タイムラインのパネルの下（レーンの下）に出す。別パネルにしない（レイアウト・メニューを増やさない）。レーンの名前を選ぶと出て、時間軸（ズーム・スクロール）はレーンと共有する。高さはパネルの半分（120〜340pt）
- **②の編集**: キー・制御点のドラッグは①と同じく作業用の複製に溜め、離したときに `SetMotionCurve` 1 回。種別の切替も `SetMotionCurve`（`Curve::set_kind`。終点は動かさず、新しいベジェの制御点は直線の 1/3・2/3）。制御点の移動は `Curve::move_control`（時間は区間の両端に収める。端に収めれば時間は単調で `value_at` が崩れない）
- **②の複数選択**: Shift を押してキーを押すと選びに足す・外す。ドラッグで選んだキー全部を同じ量だけ動かす（前後のキーで止まる）。「値を揃える」は主キーの値に揃える。時間の揃えは入れない
- **③のコマンド**: `AddExpression` `RemoveExpression` `RenameExpression` `SetExpressionFade` `SetExpressionParameter`（項目の追加と置換を 1 本に。パラメータで一意）`RemoveExpressionParameter`。`ExpressionBlend` に serde を付け、`Expression` を `Editable`（Undo）にした。パラメータは表情が指していると削除できない（`validate`）
- **③のプレビュー**: `ExpressionPlayer` を使わず、ビューの値に重み付きで当てる（加算 `base + v*w`、乗算 `base*(1+(v-1)*w)`、上書き `base*(1-w)+v*w`）。始めたときの値を覚え、止めると戻す。アプリに `tsukumoe-runtime` を足さない（① と同じ）。表情が互いに重なる合成とフェードの時間経過は見ない
- **③のパネル**: `expressions`。Modeling は履歴・タイムラインの隣、Animation はタイムラインの隣。名前の変更 UI は無い（コマンドはある）
- **②で入れなかったもの**: 値方向のズーム・スクロール（値の範囲はパラメータの範囲に合わせて自動）、ベジェの制御点の左右の連動、カーブのコピー・貼り付け

## 検証（変更したクレートだけ）

- `tsukumoe-core`: 各コマンドの適用・Undo・不正値の拒否のテスト。4 種のセグメントの切替で終点が動かないこと
- `tsukumoe-app`: タイムラインとカーブエディタの kittest（キーの追加・移動、種別切替、スクラブ）。スナップショットは主要な状態だけ
- `tsukumoe-format`: モーション・表情を含むプロジェクトの保存 → 開き直しが同じになる（既存のテストに追加）
- 実機の GUI 操作は `gui-checklist.md` に追記
