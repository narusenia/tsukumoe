# MCP の描画ツール（`tsukumoe-cli`）

- REQ: REQ-AI-002
- 単位: M5-01b
- 状態: 計画中
- 依存: M5-01, M1-10
- クレート: `tsukumoe-cli`（MCP のツール・CLI の引数）、`tsukumoe-gpu`（メッシュの集合だけを描く・薄く描く）

## 目的

エージェントが編集の結果を MCP だけで目視確認できるようにする。部位を絞って描く・寄せる・複数の姿勢を並べることで、少ない呼び出しと小さい画像で確かめられるようにする。

## 範囲

- `render` ツール
  - 引数: `params`（姿勢）、`view`（範囲。省略時は自動）、`size`（省略時は長辺 512）、`only`（パーツ名・メッシュ名の配列。パーツは配下を再帰的に含む）、`crop`（`only` の外接矩形に余白 5% で寄せる。既定 true）、`context`（`none` / `ghost`。`ghost` は選ばなかった要素を不透明度 20% で描く）、`background`（透明 / 色）
  - `poses`（姿勢の配列）を渡すと、同じ範囲で横に並べた 1 枚を返す。各コマの下に姿勢を文字で返す（画像に文字は描かず、テキストのコンテンツとして並び順を返す）
  - 応答は MCP の image コンテンツ（`image/png`、base64）とテキスト（範囲・サイズ・並び順）
- `sweep` ツール: パラメータ 1 つを最小〜最大で `steps`（既定 5、最大 16）段描いて並べる。ほかの引数は `render` と同じ
- `render_motion` ツール: モーションを時刻 `times`（または等間隔 `frames` 枚、最大 16）で評価して並べる。物理は M5-01d の `simulate` に任せ、ここでは物理なし
- `pick_at { x, y, params?, view?, size? }`: 画像上の座標から、その点に描かれている（前面から順に）メッシュ名を返す。描画リストの三角形との当たり判定で、不透明度 0 とテクスチャのアルファ 0 の点は除く
- `snapshot { name }` / `compare { name, ... }`: `render` の結果を名前付きでセッション内に保持し、現在のモデルで同じ引数で描いた画像との差分（差の画素数・差分画像）を返す。保持はメモリのみで最大 16 枚
- CLI: `tsukumoe render` に `--only` `--crop` `--context` `--poses` を、`tsukumoe sweep` を足す
- 範囲外: 線・頂点・格子などの重ね描き（M5-01c）、物理込みの描画（M5-01d）、エディタの画面の取得（M5-01i）

## 方針

- `tsukumoe-gpu` の `render_only`（メッシュ 1 つ）を、メッシュの集合と「ほかを薄く描く」に広げる。マスクの元になるメッシュは `only` に入っていなくてもマスク用には描く（見た目を実際と変えない）
- パーツ → 配下メッシュの展開は `tsukumoe-core` の関数にする（M5-01a の `get_tree` と共有）
- 並べた画像は 1 枚の合計が 4096×4096 を超えないよう、コマのサイズを縮める
- base64 は自前の小さい実装（依存を足さない。M4-05 の WAV と同じ方針）
- GPU を初期化できない環境では、描画系のツールだけがツールエラーを返す（サーバは動き続ける）。`Headless` はセッションで 1 度だけ作って使い回す

## 検査

- `only` の描画が、ほかのメッシュを非表示にした描画と画素で一致する（マスクを使うメッシュを含むテストモデルで）
- `crop` の範囲が選んだメッシュの外接矩形を含む
- `poses` の各コマが、単独の `render` と一致する
- `pick_at` が、既知の点で期待のメッシュ名を返す。透明な点では返さない
- `compare` が、同じモデルで差 0、1 コマンド適用後に差ありを返す
- MCP の image コンテンツが仕様どおり（`type`・`data`・`mimeType`）で、デコードすると PNG になる
- 上限超え（`steps` 17、巨大な `size`）がツールエラーになる

## 受入条件

- [ ] 指定した姿勢の画像を MCP で受け取れる
- [ ] 部位を絞って・寄せて・並べて描ける
- [ ] 画像の点からメッシュ名に戻れる
- [ ] 編集前後の差分を MCP で受け取れる
