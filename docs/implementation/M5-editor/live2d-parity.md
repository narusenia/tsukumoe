# Live2D Cubism Editor との機能差の解消（M5 の追加単位）

- REQ: REQ-EDIT-002〜007、REQ-UI-001（エディタの操作性）。方針は、Cubism Editor にある機能は Tsukumoe のエディタでも作ること（利用者の決定、2026-11-02）
- 状態: 計画中（ここは単位の洗い出し。各単位の計画書は、着手前に別ファイルで書く）
- 調査の出どころ: メンテナーの知識による Cubism Editor の機能の列挙（公開マニュアル相当）。マニュアルとの突き合わせは未実施。moc3 の形式・SDK・他人のモデルは調べていない（ADR-0016）

## 追加する単位

| ID | 単位 | 中身 | 規模 |
|---|---|---|---|
| M5-02d | [削除の確認ダイアログ](delete-confirm.md) | 削除の確認、次回から表示しない、設定で戻す | S |
| M5-02e | [表示補助](view-aids.md) | 参照画像、グリッド、定規、ガイド、スナップ、統計・情報表示（キャンバスの回転と複数ビューは作らない。計画書に理由） | M |
| M5-03a | PSD の差分再読み込みとテクスチャアトラス | 既存の作業を保った PSD の更新、テクスチャアトラスの編集・自動配置 | M |
| M5-04c | 作成補助 | 左右対称編集（片側を動かすと反対側も動く）、投げ縄選択、メッシュの頂点の結合 | M |
| M5-05c | ベジェ・ワープと糊 | ワープの曲線補間の切替と UI、糊（グルー）の作成・編集 | M |
| M5-06d | 描画まわりのキーフォーム | マスク（クリッピング）パネル、描画順グループ、乗算・スクリーン色のキーフォーム編集 | M |
| M5-06e | パラメータの整理 | パラメータグループ、並べ替え、パラメータのコピー・貼り付け | S |

| M5-09a | 動画・連番画像の書き出し | 動画と連番画像の書き出し（ヘッドレスのレンダを使う） | S |

## 既存の単位（計画済み）

M5-05a（ボーン・スキニング・ウェイトペイント）、M5-06b・06c（形の編集、反転コピーと多次元・格子表示）、M5-07（物理）、M5-08（モーションと表情）、M5-09（書き出し）。REQ-AI-006（顔の動きの自動生成）は M6。

## 順序の案

1. M5-02d（削除の確認。誤操作の被害を先に減らす）
2. M5-06b → 06c（進行中・続き）
3. M5-04c（左右対称編集。06c の反転コピーと同じ土台を使う）
4. M5-06d、M5-05c、M5-06e（モデリングで毎回使うものから）
5. M5-05a、M5-07、M5-08、M5-09、M5-09a
6. M5-02e、M5-03a、M5-10

## 確認が要るもの

- 各単位の詳細（範囲・コマンド・形式の変更の有無）は、着手前に計画書を書いて利用者に確認する
- requirements 側（REQ-EDIT-002〜007 の受入条件）に、上の機能を書き足すかは、利用者に確認する
