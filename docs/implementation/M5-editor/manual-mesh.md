# 手動メッシュの作図（`tsukumoe-core` / `tsukumoe-app`）

- REQ: REQ-EDIT-002（メッシュ編集）の操作性の改善
- 単位: M5-04d
- 状態: 計画中
- 依存: M5-04、M5-04b、M5-06b（キーフォームつきメッシュの扱いをそろえるため）
- クレート: `tsukumoe-core`（メッシュ編集の純粋関数）、`tsukumoe-app`（メッシュツール、ツールバー）。新しい依存クレートは足さない

## 目的

手で頂点と辺を置いて、きれいなメッシュを作りやすくする。いまは手動分割が既定（頂点の追加は三角形を分けるだけで、自動の再分割は `D` `G` `C` を押したときだけ）だが、次の 3 点が書きづらい。

- 辺を引くのが「頂点を 2 つ選んで `E`」で遅い
- 頂点は既存の外周の内側にしか打てず、外周を後から広げられない
- 辺を消す手段がなく、穴を作れない

## 範囲

- **辺ペン**（作図モード）
  - アクション `mesh.edge-pen`（キー `P`、暫定。ツールバーにもボタンを足す）で入る・出る。メッシュツールの中の副モード
  - 頂点 A をクリックして B をクリックすると、A-B の辺を引く（既存の `mesh_edit::connect`）。B が次の始点になり、続けて引ける。Esc・右クリック・空きのダブルクリックで連鎖を終える。ドラッグで A から B へ引いても同じ
  - 空きの場所をクリックすると、そこに頂点を足し（外周の内側・外側のどちらでも）、始点とつなぐ。足した頂点が次の始点
  - 引けない辺（外周や頂点が邪魔、重なる）は、トーストで理由を伝えて何も変えない
  - 引く前のプレビュー（始点からカーソルまでの線）を出す
  - 確定は辺ごとに `SetMeshGeometry` 1 回（1 辺 = undo 1 回）
- **外周の追加**（頂点を外周の外に打つ）
  - 通常のメッシュツールでも、外周の外をクリックすると頂点を足す。新しい頂点から、見える外周の辺へ三角形を張って外周を広げる（既存の三角形と重ならない範囲で。見える外周の辺が複数あるときは、最も近い辺 1 本に張り、残りは辺ペンでつなぐ）
  - UV は、最も近い三角形の座標系を外へ延ばして求める（テクスチャの範囲外になる点は拒否する）
  - 確定は `SetMeshGeometry` 1 回
- **辺の削除**
  - アクション `mesh.delete-edge`（キー `X`、暫定。辺だけを選んでいるときの `Delete` も同じ）。選択中の辺の両側の三角形を消す（外周の辺なら片側だけ）。結果は穴または縮んだ外周になる
  - どの三角形にも属さなくなった頂点は取り除く。メッシュの三角形がなくなる削除は拒否する
  - 確定は `SetMeshGeometry` 1 回
- **キーフォームつきメッシュ**: 頂点の数や三角形が変わる操作なので、M5-06b と同じく拒否する（同じ文言）
- 範囲外: 穴の埋め直し（辺ペンで三角形をつくり直す）、複数メッシュにまたがる辺、メッシュの分割・結合、自動で穴を検出する機能

## 方針

- 画面状態（作図モード、始点、プレビュー）は編集モデルに入れない（ADR-0019）。新しい `Command` は足さない。確定は既存の `SetMeshGeometry` 1 本
- 純粋関数は `tsukumoe-core::mesh_edit` に足す（`extend_outline` と `remove_edge` など。名前は実装時に決める）。UI は新しい配列を作ってコマンドを送るだけ
- 削除の確認ダイアログ（M5-02d）の対象に `mesh.delete-edge` を含める。M5-02d が先に入っていれば、同じ仕組みに載せる
- 16 ms の予算を守る。プレビューの描画は軽く保つ

## 受け入れ基準

- 辺ペンで、頂点から頂点へ辺が引ける。連続して引け、Esc で終わる。引けない辺は理由が出て、何も変わらない
- 外周の外に頂点が打て、外周が広がる。三角形が重ならない（テストで、全三角形の符号が正で、重なりがないことを確かめる）
- 辺の削除で穴ができる。外周の辺は外周が縮む。孤立した頂点が消える
- いずれも undo 1 回で元に戻る。キーフォームつきメッシュは拒否される
- 画像比較（ライト・ダーク。辺ペンのプレビュー）、`mesh_edit` の純粋関数のテスト、`tsukumoe-core` の wasm32、clippy、fmt が通る。メッシュ頂点ドラッグの frame_time が予算内

## 未決・確認

- キー `P` `X` は暫定。実機の GUI 操作は利用者の確認待ち
