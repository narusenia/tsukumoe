# M5-03a テクスチャアトラス

- REQ: REQ-EDIT-001、REQ-EDIT-007
- 状態: 実装済み・実機未確認。PSD の差分再読み込み（既存のリグを保った更新）は M5-03 で完了済みなので、この単位は残りのアトラスだけ
- 依存: M5-03、M5-09
- クレート: `tsukumoe-core`（詰め込み）、`tsukumoe-format`（ページの作成・UV の付け替え・`.tmod` への組み込み）、`tsukumoe-cli`、`tsukumoe-app`（設定・書き出し）。プロジェクト形式（`.tproj`）と `.tmod` の形式は変えない

## 決めたこと

- **いつアトラスにするか**: ランタイム形式（`.tmod`）の書き出し時だけ。プロジェクトは 1 画像 1 PNG のまま持つ。PSD の再読み込みが「レイヤ 1 枚 = テクスチャ 1 枚」を前提にしている（M5-03 の決定。「アトラス化は M5-09 の書き出しで行い、UV を付け替える」）。編集中のモデルとプロジェクトのファイルは変えない
- **詰め込み**（`tsukumoe-core::atlas`、画像の形式を知らず大きさだけを見る）: MaxRects（最良の短辺合わせ）。大きい画像から置く。ページは 2 の冪の大きさで、使った範囲を覆う最小。余白は画像のまわり（ページの縁も）。同じ入力は同じ結果
- **ページの作成**（`tsukumoe-format::atlas`）: 使うテクスチャを読み、ページに描き、余白は画像の縁の色で埋める（拡大縮小の補間で隣の画像が混ざらないように）。メッシュのテクスチャ番号と UV をページ内の位置に付け替える。番号は、ページが先、単独のものが後
- **単独のままにするもの**: メッシュの UV が 0〜1 の外に出る画像（繰り返し・ミラーのテクスチャは、ページの中では隣が見える）、ページより大きい画像。どのメッシュにも使われない画像は入れない
- **何も得しないとき**（まとめても枚数が減らない・1 枚だけ）は、書き出しは今までと同じ（バイト列も同じ）
- **設定**: アトラスを使うか（既定は使う）、ページの大きさ（256〜8192、既定 4096）、余白（0〜16、既定 2）。エディタは設定ダイアログの「ファイル」タブ、CLI は `tsukumoe convert <in> <out>.tmod [--atlas-size N] [--atlas-padding N]`（`--atlas-size 0` でアトラスなし）
- **結果の報告**: 書き出しのメッセージに「テクスチャ N 枚を M 枚にまとめた」。CLI は JSON（`textures_before`、`textures_after`、`atlas_pages`）
- **依存**: `png`（既に `tsukumoe-psd` と `tsukumoe-gpu` が使っている）を `tsukumoe-format` に足した

## 作らないもの

- アトラスの配置を手で編集する画面: 配置は書き出しのたびに自動で決まり、プロジェクトに残らない。手で動かした配置を持つと、PSD の再読み込み・メッシュの UV 編集のたびに壊れる（持ち方と同期の規則が要る）。見た目の指定（大きさ・余白）は設定で足りる
- 画像の回転（90°）での詰め込み: ランタイム側の読み手が UV の向きを前提にしているため。足すなら形式の決定が要る
- 画像の中の使われていない範囲の切り詰め: 1 画像をそのまま 1 つの長方形として扱う（PSD の取り込みは既に不透明部分に切り詰めている）

## 検証

- 詰め込み: どの画像もページの中で互いに重ならない（余白込み）、同じ入力で同じ結果、入らない画像は外す、ページは 2 の冪で最小、ちょうど埋まる
- 書き出し: 複数のテクスチャが 1 ページになり、各メッシュの UV の中心の色が元のテクスチャの色のまま。UV が 0〜1 の外のものは単独で残る。ページより大きい画像は単独で、残りは詰まる。使われない画像は入らない。壊れた PNG はテクスチャの番号つきのエラー。余白が縁の色で埋まる。同じ入力で同じバイト列。アトラスなし・1 枚だけは元のまま
- CLI: 既定で詰まり、`--atlas-size 0` で詰まらず、小さいページでは複数ページ、範囲外の値は使い方のエラー
- アプリ: 設定の範囲の丸め、書き出しで枚数が減りメッセージが出る、アトラスなしでは減らない
- 実機の GUI 操作は `gui-checklist.md`
