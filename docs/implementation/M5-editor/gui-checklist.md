## パラメータの整理（M5-06e）

- [ ] パラメータの設定ウィンドウの「グループ」欄に名前を入れると、パネルにその名前の見出しが出る。見出しで折りたためる。空にすると外れる。undo で戻る
- [ ] 行の左のグリップをドラッグすると、行の上下に線が出て、離した位置へ移る。1 回の undo で元に戻る
- [ ] グリップを別グループの行の上へ落とすと、そのグループに入る。見出しの上へ落としても入る（グループの最後）
- [ ] 並べ替えて保存し、開き直しても順序とグループが変わらない
- [ ] パラメータ名を右クリック →「キーフォームの移動: このパラメータから移す」→ 別のパラメータを右クリック →「…をここへ」で、要素が移り先の軸で動く（キーは範囲に合わせて拡縮）。1 回の undo で戻る
- [ ] 移り先に同じ要素がすでにバインドされている場合は、何も変わらずエラーが出る
- [ ] リンク済みのペア（パッド）はドラッグできない
- [ ] 狭いパネルでも数値欄とリセットボタンがはみ出さない

- [ ] 親デフォーマの下のメッシュを使うとき、ボーンがメッシュと同じ位置・向きに見える
- [ ] ツリーでメッシュを選び、ウェイトのモードにすると、頂点が重みの色で出る。ボーンを選んで塗ると、頂点の色が変わる（加算・減算・ぼかし、半径・強さ）。離したとき Undo 1 回で戻る
- [ ] 1 つの頂点に 5 本目を塗っても、最も弱いボーンが落ちて 4 本に収まる
- [ ] ボーンのキーフォーム（キーパネルでボーンをバインド）で、パラメータを動かすとメッシュが曲がる。キーの上でだけボーンを動かせ、キーの外ではエラーが出る
- [ ] 保存して開き直しても、ボーン・重みが同じ

## M5-02e 表示補助（[計画書](view-aids.md)）

- [ ] ビューポート右上の目のアイコンで箱が開く。「グリッド」「定規」「スナップ」「情報」を切り替えると、その場で変わる
- [ ] グリッドの間隔を 0 にすると、ズームに合わせた丸い間隔になる。数値を入れるとその間隔になる
- [ ] 定規の目盛りと数字が、ズームで変わり、ポインタの位置に印が動く
- [ ] 上の定規からドラッグで水平のガイドが、左の定規から垂直のガイドができる。ガイドをドラッグで動かせ、定規の上で離すと消える。「ガイドを消す」で全部消える
- [ ] スナップを入れて、メッシュの頂点・ワープの点・回転の原点・ボーンの関節をドラッグすると、グリッドの間隔ごとに動く。範囲選択の箱はスナップしない
- [ ] スナップを入れてボーンツールで空きをクリックすると、グリッドかガイドに乗った位置にボーンができる
- [ ] 「参照画像を読み込む」で PNG を選ぶと、モデルの後ろに出る。不透明度・拡大率・位置・表示のオンオフが効く。壊れた PNG はエラーで、何も変わらない
- [ ] 「情報」で、メッシュ・頂点・三角形の数、ズーム、ポインタ座標が右下に出る
- [ ] 保存して開き直すと、設定・ガイド・参照画像が同じ。何も設定していないプロジェクトの `editor/` に余計なファイルが増えない

## M5-03a テクスチャアトラス（[計画書](texture-atlas.md)）

- [ ] 設定の「ファイル」タブに、「書き出しでテクスチャをアトラスにまとめる」、ページの大きさ、余白がある。範囲の外は丸められる。「リセット」で既定（使う・4096・2）に戻る
- [ ] レイヤの多い PSD から作ったモデルを書き出すと、メッセージに「テクスチャ N 枚を M 枚にまとめました」が出る
- [ ] 書き出した `.tmod` を `tsukumoe inspect` で見ると、テクスチャが M 枚。ビューア / `tsukumoe render` の見た目が、アトラスなし（設定でオフにして書き出したもの）と同じ。レイヤの境目に隣の絵の色がにじまない
- [ ] 書き出しの前後で、プロジェクトの `textures/` と、エディタ上のモデルが変わらない（未保存の印も変わらない）
- [ ] 設定でオフにして書き出すと、テクスチャの枚数が減らない
