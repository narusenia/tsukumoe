## パラメータの整理（M5-06e）

- [ ] パラメータの設定ウィンドウの「グループ」欄に名前を入れると、パネルにその名前の見出しが出る。見出しで折りたためる。空にすると外れる。undo で戻る
- [ ] 行の左のグリップをドラッグすると、行の上下に線が出て、離した位置へ移る。1 回の undo で元に戻る
- [ ] グリップを別グループの行の上へ落とすと、そのグループに入る。見出しの上へ落としても入る（グループの最後）
- [ ] 並べ替えて保存し、開き直しても順序とグループが変わらない
- [ ] パラメータ名を右クリック →「キーフォームの移動: このパラメータから移す」→ 別のパラメータを右クリック →「…をここへ」で、要素が移り先の軸で動く（キーは範囲に合わせて拡縮）。1 回の undo で戻る
- [ ] 移り先に同じ要素がすでにバインドされている場合は、何も変わらずエラーが出る
- [ ] リンク済みのペア（パッド）はドラッグできない
- [ ] 狭いパネルでも数値欄とリセットボタンがはみ出さない

- [ ] Secondary ボタン（設定ダイアログ、フライアウトの「グリッドを敷く」など）に枠線があり、ボタンとして見える。ツールバーとツリー行の Ghost は塗りなしのまま
- [ ] ⑤ 文言: 画面に「ツリー」「Part」「束縛」「糊」が残っていない（パーツ・バインド・グルー）。ヒントの修飾キーが macOS で ⌘、他で Ctrl と出る
- [ ] ⑤ セクション見出し（英語）が大文字化されず、書いた通りに出る

- [ ] ③ パネルのタブが、アイコンと名前の両方で出る（設定でアイコンのみに切替可、再起動後も保持）
- [ ] ③ バインド済み（キーフォームあり）のメッシュ・デフォーマの行に、名前の右へリンクアイコンが出る。未バインドの行には出ない
- [ ] ③ 選択ツールでビューポートのメッシュに乗せると、ツリーの行が光る。ツリーの行（メッシュ / パーツ / デフォーマ）に乗せると、ビューポートで配下メッシュの縁が強調される。離すと消える
- [ ] ③ ツリーのメッシュ行に、そのメッシュのテクスチャ切り出し（16px）が出る。テクスチャのないメッシュはアイコンのまま
- [ ] ③ メッシュに 0.5 秒乗せると、サムネイル・頂点数・親デフォーマ・マスク・描画順のカードがポインタ横に出る。動かすと消える。ツリー行でも同じ
- [ ] ③ パーツ行に乗せると、ビューポートで配下メッシュの縁に加え、薄い囲み枠が出る
- [ ] ② メッシュツールで「グリッドを敷く」直後、+ / − キーとホイールでグリッド数が 1 ずつ増減し、メッシュが敷き直される。Undo 1 回で敷く前に戻る。他の操作をした後は + / − とホイールがふつうのズームに戻る
- [ ] ④ 選択ツールでビューポートのメッシュを右クリックすると、そのメッシュが選ばれ、メニュー（隠す / 表示、ソロ、名前を変更、複製、削除、親、デフォーマで囲む）が出る。何もない所では出ない。ツリー行のメニューにも隠す / 表示とソロが増えている
- [ ] ④ メッシュ / デフォーマツールの右クリックメニューが、全体の項目・「頂点」「辺」のサブメニュー・デフォーマ作成（区切りの下）に分かれている。選択に応じて無効の項目は灰色。サブメニューの項目を選ぶとメニューが閉じて実行される
- [ ] ④ ツリー行メニューに、区切りと、名前変更 F2・複製 ⌘D・削除 Del のショートカット表示がある。パーツ / 展開できる行には「配下を…」サブメニュー（配下を選択・すべて開く・すべて閉じる）
- [ ] ④ パラメータ名の右クリックに、既定値に戻す・バインド・バインド解除・ここにキーを追加・グループへ移動（他のグループがあるときだけ）が増えている。選択がないときのバインドはエラー表示
- [ ] ⑥ ビューポートで Shift+R を押すと、直前に実行したメッシュ / デフォーマの操作（グリッドを敷く、結合など）がもう一度実行される。何も実行していないときは何も起きない
- [ ] ⑥ プロジェクトを開いていないとき、ビューポートに「新規プロジェクト / 開く / PSD から新規」のボタンと最近のプロジェクト（最大 6 件）が出る。どれを押しても、メニューの同じ項目と同じ動き
- [ ] ⑥ メニューバー右の Modeling / Animation の切替タブが出ない（Modeling だけ）。以前 Animation を選んだ状態で起動しても Modeling で開く
- [ ] ⑥ メッシュを選ぶとインスペクタに「ブレンドモード」（通常 / 加算 / 乗算）の選択欄が出る。変えるとビューポートの見た目が変わり、Undo で戻る
- [ ] ⑥ キーパネル: バインド / 解除が先頭、軸の切替ボタンが「行: 名前 / 列: 名前」（絵文字の矢印なし）、反転コピーが折りたたみになり、中心線 x の欄に名前が付き、コピー元が「名前 (1, 2)」の形で出る
- [ ] ⑥ 数値欄（インスペクタ・パラメータ等の `number`）: Shift を押しながらドラッグすると 1/10 の速さで動く。文字を打っている途中で Esc を押すと、入力前の値に戻って確定されない（Undo 履歴に載らない）
- [ ] ⑥ 数値欄をダブルクリックすると既定値に戻る: パラメータ行（そのパラメータの既定値）、設定ダイアログ（頂点 / 辺の半径・履歴数・溶接比・ミラー許容差・自動保存の間隔・ドラッグ感度は初期設定）、インスペクタ（不透明度 1、回転デフォーマの角度 0 / 拡大率 1）。範囲・原点・点座標は既定値なしで何も起きない
- [ ] - [ ] - [ ] ⑥ 設定ダイアログ（メニュー > パイメニューの設定、または設定 > パイメニュー）: 縦に十分な高さがあり、左にパイの見取り図（番号）、右に番号付きの一覧がある（見切れ・不自然な距離なし）。上のタブで「共通 / 選択 / メッシュ編集 / デフォーマ」を切り替え、ツールのタブでは「このモード専用の割り当てにする」で共通からコピーして別々に編集できる。各スロットは「動作」か「グループ（サブメニュー）」に切り替えられ、グループは名前を付けられ、中のスロットも増減できる。スロット数は 1〜12。Q 長押しのパイが今のツールの割り当てで開く
- [ ] ② デフォーマツールの設定に、ワープの格子数のチップ（2×2 / 4×4 / 8×8 / 自動）が出る。「自動」（既定）は囲む対象の縦横比から行 × 列を決める（長い辺が 5 分割）。数値を手で変えると自動が外れる
- [ ] ② メッシュツールの輪郭設定に「高精度（サブピクセル）」のチェックが出る。チェックは設定行の下に左端をそろえて出る。入れると「間引きの許容誤差」が 0.5px まで下がり（それ以下の値はそのまま）、入れて「輪郭から作る」を実行すると、アンチエイリアスされた絵の縁に沿った輪郭になる（切ると従来どおり）
- [ ] ② メッシュツールの輪郭設定の先頭に「面 / 線画」の切替がある。「線画」にして髪の毛・線画のような細い線のテクスチャで「輪郭から作る」を実行すると、線ごとに線に沿った帯状のメッシュ（内側に中心線の点つき）ができ、分岐では線ごとに分かれる。「線の太さ」を 0 にすると画像から測り、値を入れるとその太さに固定。線画のときは「高精度」チェックは出ない（面のときだけ）

- [ ] ⑥ 配色: ダーク / ライト両方で、セレクト・数値欄・ボタンがダイアログや各パネルの背景から見分けられる（薄い枠あり）。特に設定ダイアログのパイメニュータブ。見づらい所があれば場所を教えてほしい
- [ ] ⑥ 配色の監査後: ダークのプライマリボタン・選択行・パイの選択項目の文字が暗色（accent の上）で読める。ライトのエラー / 警告 / 成功の色が少し濃くなり、淡い面の上でも読める。Figma Dark / Figma Light テーマは外部の配色のため基準未達の組がある（テストは報告のみ）

- [ ] ④ 複数選択（Ctrl / Shift）したメッシュ・デフォーマの 1 つを右クリック > 親を設定 で、選択した全部に同じ親が付く（Undo 1 回）。選択した行をデフォーマの行へドラッグしても、選択全体が入る。「親を外す」も選択全体に効く
- [ ] ④ 子（メッシュ・デフォーマ）がいるデフォーマを削除できる。子は親なしになり、見た目の位置は変わらない（確認ダイアログの件数に子は数えない）。Undo 1 回で、デフォーマも子の親も元に戻る

- [ ] ② プロポーショナル編集のオプション箱の半径欄の右に切替ボタン（照準アイコン）が出る。押すと半径が「モデル空間で固定」になり（欄の単位が pt からモデル長に変わる）、ビューポートをズームしても、ドラッグで動く頂点の範囲が変わらない（円は画面上で拡縮する）。ホイールでの半径変更も効く。もう一度押すと画面基準（pt）へ戻る

- [ ] ④ メッシュツールの設定箱の下の「初期化」ボタン、右クリックメニュー、Shift+G で、メッシュが UV の範囲を覆う四角形（頂点 4 つ・三角形 2 つ）に戻る。Undo 1 回で戻す前に戻る。キーフォームのあるメッシュは形の変更として断られる

- [ ] ⑥ 設定ダイアログ（ショートカット・表示・編集・ファイル・操作の各タブ）とインスペクタで、名前の列と入力欄の開始位置がそろっている。ショートカット欄は名前との間に余白があり、幅が適度（入力欄が画面いっぱいに伸びない）。長い名前は「…」で切れ、ホバーで全体が見える
- [ ] ⑥ 輪郭の均等化: 輪郭から作るの「輪郭の点を均等に並べる」をオンにして作ると、点の間隔がそろう（角は残る。点の数は変わらない）。既存のメッシュは右クリック →「輪郭の点を均等な間隔に並べ直す」か Shift+C（メッシュツールのオプション欄は「輪郭を均等化」）。内側の点は残り、Undo で戻る。穴のあるメッシュはエラー表示になる

- [ ] ④ ソロ表示中、ビューポート上部の「ソロ表示中: 名前」の右に ✕ がある。押すとソロが解除され、全体が表示に戻る
- [ ] ④ ビューポートで / キーを押すと、選択中のパーツ・メッシュ・デフォーマだけが表示される（ソロ）。同じものを選んだままもう一度押すと解除。別の項目を選んで押すとそちらに替わる。設定 > ショートカットで変更できる
