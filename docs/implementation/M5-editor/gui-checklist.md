## M5-04d 手動メッシュの作図

- [x] メッシュツールの右上オプション欄に、ポインタ（選択）と鉛筆（辺ペン）のアイコンボタン。使用中のほうが塗りつぶし。ホバーで名前が出る
- [x] `P` で辺ペンと選択が切り替わる。切り替えると連鎖が終わる
- [x] 辺ペン: 頂点 A → 頂点 B とクリック → 辺が引かれる。続けて C をクリックすると B-C も引かれる（B が次の始点）
- [x] 始点の頂点に輪がつき、始点からカーソルまで線のプレビューが出る
- [x] A から B へドラッグしても辺が引ける
- [x] 辺ペンで空きをクリック → 頂点が足され、始点とつながる。三角形内でも、外周の外でもよい
- [x] 引けない辺（間に外周や頂点がある）はトーストで理由が出て、何も変わらない
- [x] Esc と右クリックで連鎖が終わる（右クリックでメニューは出ない）
- [x] 1 辺 = Undo 1 回。履歴パネルに `mesh_connect` などが並ぶ
- [x] 選択ツールで Mod+クリック → 外周の外に頂点が足され、外周が広がる。三角形が重ならない
- [x] メッシュがテクスチャいっぱいのとき、外へ打つと「テクスチャの外側には頂点を置けません」が出る
- [x] 辺を 1 本選んで `X` → 両側の三角形が消えて穴ができる（確認ダイアログが出る）
- [x] 辺だけ選んだ状態の `Delete` も同じ。外周の辺なら外周が縮む。孤立した頂点が消える
- [x] 三角形が 1 つしかないメッシュで辺を消すと「三角形が残らないため…」が出る
- [x] キーフォームつきメッシュで辺ペン・辺削除・外周の拡張 → 拒否される（M5-06b と同じ文言）
- [x] 右クリックメニューに「辺ペン」「選択した辺を削除」が出る。辺未選択では削除が無効
- [x] 大きいメッシュで頂点ドラッグが重くならない（16 ms）

## M5-06c-1 キーフォームの反転コピー

- [x] 左右のメッシュ（またはワープ・回転）にバインドしたパラメータで、左のキーフォームを動かす → パラメータパネルで左を選び「反転コピー元」 → 右を選んでスライダを同じキーに合わせ「ここへ反転して貼り付け」 → 右が左右対称の形になる
- [x] ツリーの行の右クリックメニュー（メッシュ・デフォーマ）にも「反転コピー元」「ここへ反転して貼り付け」があり、同じ結果になる
- [x] 貼り付けは undo 1 回で戻る
- [x] キー位置にいないとき・コピー元なしのとき・種類が違うとき・頂点が対にならないとき、トーストで断る
- [x] 中心線の欄を空にするとモデル中心、数値を入れるとその x で反転する

## M5-06c-3 キーパネルと 2 軸のパッド、軸の入れ替え

- [x] 「キー」パネルが新しくある（右側の「インスペクタ」の隣のタブ。パネルメニューにも出る）。パラメータパネルはスライダ一覧だけで、編集部が大きく場所を取らない
- [x] パラメータ名をクリックすると「キー」パネルがそのパラメータの前後キー・キー追加・削除・バインド・バインド解除を受ける
- [x] パラメータ名のダブルクリックか右クリック →「パラメータの設定」で、名前・最小/既定/最大・繰り返し・削除のウィンドウが開く
- [x] 2 軸以上の要素を選ぶと、キーパネルに正方形のパッドが出る。◆ = キーの組み合わせ（塗り = 編集済み、中抜き = 既定のまま、青 = 編集中、黄の枠 = 反転コピー元）、● = スライダの位置
- [x] パッドのクリック・ドラッグで 2 つのスライダが同時に動く。◆の近くで吸着し、Shift で吸着しない
- [x] 3 軸以上のとき、↕ ↔ ボタンで縦・横の軸を切り替えられ、残りの軸は今のスライダに近いキーで固定される
- [x] ◆の右クリックで「反転コピー元」「ここへ反転して貼り付け」
- [x] パラメータ名の右クリック →「リンクする相手」で 2 つのパラメータをリンクすると、一覧で 1 つのパッド（Live2D と同じ。白丸 = 選択中の要素のキー、青丸 = 現在値、右に数値欄 2 つ）になる。クリック・ドラッグで両方が動き、白丸の近くで吸着（Shift で解除）。「リンクを解除」で元のスライダに戻る
- [x] 各行の右端の「既定値に戻す」ボタンで、そのパラメータだけ既定値に戻る（既定値のときは薄く押せない）。リンクのペアは 1 つのボタンで 2 つとも戻る
- [x] リンクはプロジェクトを保存して開き直しても残る。パラメータの名前変更で追随し、削除で外れる
- [x] 軸の入れ替えボタン（上下矢印）で縦横が入れ替わり、見た目は変わらない。undo 1 回で戻る

## M5-04c 作成補助（[計画書](mesh-assist.md)）

- [ ] 左右対称オン: 左側の頂点をドラッグ → 右側の鏡像の頂点が左右反転して動く。undo 1 回で両方戻る
- [ ] 左右対称オン + プロポーショナル編集: 周囲の頂点も鏡像側で同じように動く
- [ ] 左右対称オフ: 動かした頂点だけが動く。軸上・鏡像のない頂点だけ動かしても壊れない

- [ ] メッシュツール: Mod を押しながら空きをドラッグ → 曲線と薄い塗りが出て、離すと内側の頂点が選ばれる。Shift で追加。Mod + クリックの頂点追加は今までどおり
- [ ] 選択ツール: 空きをドラッグ → 曲線が出て、離すと重心が内側のメッシュが選ばれる。Shift で追加。空振りの投げ縄は選択を外す（Shift 中は保つ）。クリックでの選択は今までどおり

- [ ] 重なった頂点がある状態で `Shift+J`（メニュー「重なりそうな近い頂点を結合」）→ まとめて 1 点になる。なければ「変更なし」
- [ ] キーつきメッシュ（キー位置の編集中）でも、左右対称編集・結合のあと別のキーへ動かして破綻しない
- [ ] ライト・ダークの両方でオプション欄と投げ縄の見た目が崩れない
