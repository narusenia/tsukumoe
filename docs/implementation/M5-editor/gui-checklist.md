## M5-02d 削除の確認ダイアログ

- [ ] ツリーで Part を選んで `Delete` → ダイアログ。名前、「N 件が削除されます」、「この操作は取り消せます。」が出る
- [ ] 開いた直後のフォーカスが「キャンセル」。Enter を押してもモデルは変わらない（ダイアログが閉じるだけ）
- [ ] 「削除」をクリック → 削除される。Undo 1 回で戻る
- [ ] Cmd/Ctrl+Enter で削除される。Esc とダイアログ外のクリックでキャンセル
- [ ] ダイアログが開いている間、ビューポートのクリック・`Delete`・ツリーのキー・ショートカット（Cmd+Z など）が効かない
- [ ] 複数選択（Shift/Cmd クリック）→ 1 回の確認で、件数が正しい。名前は 3 つまでで「ほか N 件」
- [ ] メッシュ 1 件・デフォーマ 1 件の削除も確認が出る
- [ ] ツリーの右クリック「削除」、パラメータパネルのゴミ箱・キー削除（−）・バインド解除でも確認が出る
- [ ] 「次回から表示しない」を付けて削除 → 次から確認なし。アプリを再起動しても保たれる
- [ ] 「表示 > 削除の確認」で種類ごとにオン・オフできる。「すべて確認する」で全部戻る
- [ ] メッシュ編集で頂点を選んで `Delete` → 確認。キャンセルしても選択が残る
- [ ] ライト・ダークの両方で見た目が崩れない

## M5-04d 手動メッシュの作図

- [ ] メッシュツールの右上オプション欄に、ポインタ（選択）と鉛筆（辺ペン）のアイコンボタン。使用中のほうが塗りつぶし。ホバーで名前が出る
- [ ] `P` で辺ペンと選択が切り替わる。切り替えると連鎖が終わる
- [ ] 辺ペン: 頂点 A → 頂点 B とクリック → 辺が引かれる。続けて C をクリックすると B-C も引かれる（B が次の始点）
- [ ] 始点の頂点に輪がつき、始点からカーソルまで線のプレビューが出る
- [ ] A から B へドラッグしても辺が引ける
- [ ] 辺ペンで空きをクリック → 頂点が足され、始点とつながる。三角形内でも、外周の外でもよい
- [ ] 引けない辺（間に外周や頂点がある）はトーストで理由が出て、何も変わらない
- [ ] Esc と右クリックで連鎖が終わる（右クリックでメニューは出ない）
- [ ] 1 辺 = Undo 1 回。履歴パネルに `mesh_connect` などが並ぶ
- [ ] 選択ツールで Mod+クリック → 外周の外に頂点が足され、外周が広がる。三角形が重ならない
- [ ] メッシュがテクスチャいっぱいのとき、外へ打つと「テクスチャの外側には頂点を置けません」が出る
- [ ] 辺を 1 本選んで `X` → 両側の三角形が消えて穴ができる（確認ダイアログが出る）
- [ ] 辺だけ選んだ状態の `Delete` も同じ。外周の辺なら外周が縮む。孤立した頂点が消える
- [ ] 三角形が 1 つしかないメッシュで辺を消すと「三角形が残らないため…」が出る
- [ ] キーフォームつきメッシュで辺ペン・辺削除・外周の拡張 → 拒否される（M5-06b と同じ文言）
- [ ] 右クリックメニューに「辺ペン」「選択した辺を削除」が出る。辺未選択では削除が無効
- [ ] 大きいメッシュで頂点ドラッグが重くならない（16 ms）
