## 決定事項（正本は ADR）
- スキニングはデフォーマ前、ボーンはメッシュの親局所空間（ADR-0021）。物理はドライバ直後・固定刻み 1/60 秒（ADR-0022）。名前は ADR-0023
- 評価順: ドライバ → 物理 → クランプ → キーフォーム補間・ブレンドシェイプ → スキニング → デフォーマ → グルー → 描画順・変化検出（`docs/specifications/evaluation.md`）
- JSON は名前参照の DTO（`tsukumoe-format::dto`）。`Model` の組み立ては検証付き `Model::from_parts` のみ。ファイル構成は `file-formats.md` 1.3
- 拡張子は仮で `.tsukumoe`（プロジェクト）/ `.tmod`（ランタイム）。PSD 読み込みは M5-03（REQ-EDIT-001）で計画済み

## 公開 API の地図（`tsukumoe-core`）
- `Model::compile()` → `CompiledModel`、`Frame::new` / `evaluate` / `advance(model, dt)`、`Frame::draw_list(model)`（コピーなしのビュー）
- 編集は `Model::apply(Command)`（パラメータ・パーツ・メッシュのみ）。それ以外の組み立ては `ModelParts` + `Model::from_parts`
- 主な型: `expr.rs`（式）、`simulate.rs`（物理）、`affine.rs`、`draw.rs`

## 進め方（利用者の方針）
- ブランチ（`feat/` `fix/` `docs/` `chore/` + 具体名）→ 論理単位でコミット → `main` に `--no-ff` マージ → push。push は確認なしで進めてよいと許可済み。push 後は `gh run watch` で CI を確認（`--repo narusenia/tsukumoe`）
- コミットは英語 1 行。仕様・計画を先に書く（要件・計画・ADR は日本語、コード・形式仕様は英語）
- 依存クレートの追加は都度確認（会社ルール）。承認済みは `zip` と `schemars` のみ
- 仕様の判断は私が決めて ADR に残し、報告で示す。迷う設計だけ質問する
