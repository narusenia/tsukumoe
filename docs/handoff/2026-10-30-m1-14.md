## 注意
- 方針: ブランチ → 論理単位のコミット → `main` に `--no-ff` → push。CI は `gh workflow run ci.yml --ref <branch>`。依存追加は都度確認。AGENTS.md の docs 更新は事前確認
- 同梱フォントの Noto は部分集合（かな・約物・漢字）。外れた字は豆腐になる。足りなければ範囲を広げる
- 日本語の縦ずれは、OS フォントの fallback をやめて同梱の 1 書体系にして解消済み。補正値は使わない
- 画像・キー入力の自動操作は、最前面を確認してから。クリックは送らない
- egui 0.37 は `Id::new`・`WidgetType` が非推奨（`Id::unique`・`Role`）。zsh の `grep --include=*.md` はグロブで失敗するので引用する
