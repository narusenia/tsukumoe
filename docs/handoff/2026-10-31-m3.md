## 方針・注意
- ブランチ → 論理単位のコミット → `main` に `--no-ff` → push。依存追加・ツールのインストールは都度確認。docs の更新は事前確認
- 実装は general-purpose エージェントに委譲してきた（計画書を先に書く。コミットは英語 1 行・帰属行なし・push と merge はさせない）。`main` の作業ツリーをエージェントが使っている間は、別の worktree で作業する
- ブラウザ検証は Claude in Chrome 拡張の接続が必要（未接続だと止まる）
- Windows の CI は改行（CRLF）で 2 度落ちた。`.gitattributes` で `eol=lf` を指定済み
- zsh の `grep --include=*.md` はグロブで失敗するので引用する。BSD `sed -i` は `-i ''`
