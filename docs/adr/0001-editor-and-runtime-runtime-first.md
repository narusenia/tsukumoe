# ADR-0001: エディタとランタイムの両方を作り、ランタイムから始める

- 状態: 採用
- 日付: 2026-10-30

## 背景

Live2D はエディタ（Cubism Editor）と再生用 SDK（Cubism SDK）の二本立てである。エディタだけを作ると書き出し先が Cubism ランタイムに縛られ、代替にならない。

## 決定

エディタとランタイム SDK の両方を作る。ランタイムを先に作り、エディタは後から載せる。

## 結果

- 評価モデルと描画規則が先に固まり、エディタのデータモデルはそれに合わせられる
- エディタができるまでは、モデルを moc3 読み込み・手書き JSON・エージェント経由のコマンドで用意する
- エディタが早く要るとわかったら、マイルストーンを入れ替える（ADR-0011）
