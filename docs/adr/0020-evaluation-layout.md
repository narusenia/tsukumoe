# ADR-0020: 評価の座標系とメモリ配置

- 状態: 採用
- 日付: 2026-10-30

## 背景

M1-03 で、編集用モデルを評価用モデルにコンパイルし、フレームごとに評価する。座標系と配置は、すべての計算と M3 のバイナリ形式の前提になる。

## 決定

1. **座標系は Cubism と同じ「親デフォーマの局所空間」。** 子の座標は親デフォーマの局所空間の値で持つ。ワープの子は格子を 0〜1 に正規化した空間、回転の子は原点を基準にした空間。親のないものは描画空間そのもの。moc3 の値を損失なく写すため（ADR-0007）。
2. **評価用モデル（定義）と作業領域（フレーム）を分ける。** 定義は読み取り専用で複数体から共有でき、作業領域は 1 体ごとに持つ。
3. **全要素を連続バッファに並べる。** 全メッシュの頂点を `x0,y0,x1,y1,…` の 1 本の `f32` 配列にし、キーフォームも種類ごとに連続配列にする。要素はオフセットと長さで参照する。補間の重みはバインディングごとに 1 回だけ計算して、それを使うすべての要素で共有する。
4. **フレーム評価でヒープ確保をしない。** 作業領域はコンパイル時の大きさで一度だけ確保する。

## 結果

- 局所空間の細部（ワープ格子外の外挿、回転デフォーマが子に与える変換など）は Tsukumoe 自身の定義として `docs/specifications/evaluation.md` に書く。Cubism と一致するかは M2 の画像差分テストで検証する
- M3 のバイナリ形式は、この配置をほぼそのまま書き出せる
