# ADR-0017: 基準モデルの Seimei 形式版は生成スクリプトで作る

- 状態: 採用
- 日付: 2026-10-30

## 背景

M1 の表示と性能計測には、基準モデル（ADR-0009）の Seimei 形式版が要る。しかしエディタ（M5）はまだなく、moc3 読み込み（M2）は法務ゲート（ADR-0016）待ちである。

## 決定

パーツ表（REQ-PERF-001 の規模の内訳）から Seimei 形式の JSON を生成する CLI を `seimei-cli` に置く。M1 の表示・性能計測はこの生成物で行う。
Live2D 形式版は、自分で Cubism Editor から書き出して M2 の互換検証に使う（ADR-0016 の「自作モデル」）。

## 結果

- 性能目標の検証に必要な規模を、法務ゲートに依存せず M1 で用意できる
- 生成物は幾何学的な形状になる。見た目の品質ではなく、規模と機能網羅を目的とする
- 生成の入力（パーツ表）は差分が読める形で git 管理する
