# ADR-0028: moc3 法務ゲート（着手前確認）の結果

- 状態: 採用
- 日付: 2026-11-02

## 背景

ADR-0016 は、moc3 対応の着手前に Live2D の利用規約を確認し、結果を後続 ADR に記録すると定めた。
確認は次の 2 つで行った。

- 公開されている利用規約 3 本の読解（2026-11-02 時点）
  - Cubism Editor ソフトウェア使用許諾契約書 v1.9（2025-02-03 改定）
  - Proprietary Software 使用許諾契約書 v2.1（同）。対象は Cubism Core / MotionSync Core
  - Open Software 使用許諾契約書 v1.4（同）。対象は Cubism Components
- 株式会社 Live2D の Live2D Store/JP サポートへの問い合わせと回答（2026-11-02 受領）

## 確認した事実

### 利用規約

- Editor 5.1.2 と Proprietary 6.4 は、リバースエンジニアリング・逆コンパイル・逆アセンブルによる「本ソフトウェアのソースコードの解読」を禁じる
- 禁止の対象は Live2D のソフトウェアである。ファイル形式の独自パーサーの開発を直接禁じる条項は 3 本のどれにもない
- 「.moc3」「.cmo3」「互換ソフトウェア」を名指しする条項も 3 本のどれにもない
- Editor 1.8 / 2.1.4: Editor で作った .cmo3 / .moc3 は「出力ファイル」にあたり、用途はライセンスタイプごとの「出力ファイル用途」に限られる
  - PRO for indie、PRO for business、フリー版（一般ユーザー・小規模事業者・適格教育機関）: 営利・非営利を問わない
  - 評価版、教育機関向け、フリー版（上記以外）: 内部的または非営利の用途に限る
  - 一般ユーザー・小規模事業者の基準は直近売上高 1,000 万円未満（1.18, 1.19）
- Editor 2.2 / Open 5.5: サンプル素材と、それを含む出力ファイルは、内部的な評価とトレーニング以外に使えない
- Editor 5.1.9 / Proprietary 6.8 / Open 5.7: 出力ファイルや派生作品を、Live2D 社のミドルウェアと競合するミドルウェアと組み合わせて使う行為を禁じる
- Proprietary 2.1 / Open 2.3: Cubism Core や Components を含む派生作品の出版には、原則として Live2D 出版許諾契約書が要る。一般ユーザー・小規模事業者・適格教育機関は免除の対象になりうる（Proprietary 2.2）
- Proprietary 6.2: Core の配布・同梱は、明示の許可がある場合を除き禁止

### サポートの回答

- 独自のパーサーやエクスポーターの開発自体を直接禁じる条項はない
- .moc3 / .cmo3 の仕様は非公開であり、解析の方法によっては 5.1.2 に該当しうる。個別の可否の回答は差し控えるとのこと
- .cmo3 / .moc3 は「出力ファイル」にあたり、ライセンスタイプごとの用途制限の対象になる
- 互換ソフトウェアでの読み込み動作、互換ソフトウェアの書き出しファイルを Cubism Editor で読む動作は保証せず、推奨しない
- 互換ソフトウェアの書き出しファイルの Cubism SDK 上での動作は保証せず、推奨しない。公認・許諾も行わない
- Cubism SDK を使うアプリには Proprietary / Open の使用許諾契約書が適用される

## 決定

- 着手前確認はこの ADR をもって完了とする。許可も禁止も得られていないグレー領域として扱い、ADR-0016 の方針を変えない
  - 解析素材は、メンテナが自分で Cubism Editor から書き出した自作モデルに限る
  - Cubism Core / SDK のバイナリ、他者のモデル、既存の moc3 パーサーは見ない
  - moc3 対応は `tsukumoe-compat` の `moc3` feature に閉じ、別リポジトリ・別配布に移せる構造にする
- 公開前に弁護士の確認を受ける。次の点を論点として渡す
  - 自作モデルの解析が 5.1.2 の「解読」に当たるか
  - 利用規約が出力ファイルの用途を制限することを前提に、互換パーサーで読み込む行為と Editor のライセンスタイプの関係
  - 互換エクスポート（moc3 書き出し）を提供するかどうか
- 互換ソフトウェアとしての書き出し（moc3 / cmo3 の書き出し）は v1 の既定機能にしない。サポートが動作を保証せず推奨もしないため、提供するなら実験的機能と明記し、保証しない旨を利用者に示す
- Cubism Core は同梱も再配布もしない。Cubism SDK 上で動かす場合の出版許諾は利用者の責任であり、ドキュメントで案内する
- ドキュメントと UI では、本プロジェクトが Live2D 社の公認でも提携でもないこと、「Live2D」「Cubism」が同社の商標であることを明記する
- 検証用の画像は自作モデルだけで作る（サンプル素材は内部評価用に限られ、リポジトリに含めない）

## 結果

- M2-02（着手前確認と ADR 記録）は完了。M2-03 以降の着手条件のうち、着手前のゲートは通った
- 公開前の弁護士確認は未了。通るまで moc3 関連コードを公開しない（ADR-0016 のまま）
- ゲートが NG になった場合は、ADR-0016 のとおり Live2D JSON 群と Inochi2D だけで出す
- 規約は改定されうる。公開前に版数（Editor v1.9 / Proprietary v2.1 / Open v1.4）を再確認する
