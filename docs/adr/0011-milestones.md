# ADR-0011: マイルストーン

- 状態: 採用
- 日付: 2026-10-30

## 背景

ランタイムから作る方針（ADR-0001）と、moc3 の法務ゲート（ADR-0016）を反映した順序が要る。

## 決定

M0 基盤 → M1 core・参照レンダラ・ビューア → M2 Live2D 互換 → M3 ランタイム形式とバインディング → M4 VTuber → M5 エディタ → M6 AI リグ支援・Inochi2D・v1 リリース。
詳細は `docs/implementation/roadmap.md`。

エディタが途中で要るとわかったら、順序を柔軟に入れ替える。

## 結果

- エディタ用のコマンド API は M1 の core に先に入れ、M5 では UI を被せるだけにする
