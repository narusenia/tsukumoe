# ADR-0010: ライセンス

- 状態: 採用
- 日付: 2026-10-30

## 背景

Live2D への主な不満は、売上条件付きの SDK ライセンスとエディタのサブスクリプションである。

## 決定

- コード（ランタイム・エディタとも）: Apache-2.0 OR MIT
- 形式仕様・JSON Schema・基準モデル・サンプル: CC-BY 4.0
- AI モデルの重み: 個別ライセンスを明記し、同梱しない
- 貢献は DCO で受ける。CLA は求めない
- OSS 本体に有料前提の機能制限を入れない。収益化は要件定義の対象外

## 結果

- 依存クレートのライセンスを `cargo deny` で検査する
