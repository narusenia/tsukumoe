# ADR-0009: 性能目標

- 状態: 採用
- 日付: 2026-10-30

## 背景

数値目標がないと、SIMD・並列化・GPU 変形の要否が決まらない。

## 決定

基準モデル（ArtMesh 150 / 頂点 3 万 / パラメータ 100 / デフォーマ 80 / 物理 20 系統）を自作・同梱し、次を目標にする。

- ネイティブ 1 スレッド評価: 0.5 ms 以下
- WASM SIMD 評価: 2 ms 以下
- 参照レンダラ 1080p 描画: GPU 1 ms 以下
- ランタイム形式ロード: 20 ms 以下（テクスチャ除く）
- 50 体同時表示で 60 fps
- エディタ操作応答: 16 ms 以下
- Cubism SDK 比 2 倍以上の評価速度（手元計測のみ。結果の公開可否は SDK ライセンス確認後）

v1 は CPU + SIMD で達成を狙い、GPU 変形は未達時だけ検討する。CI でベンチマークの劣化を検知する。

## 結果

- 基準モデルの制作がクリティカルパスに入る
