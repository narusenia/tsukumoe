# ADR-0008: プロジェクト形式は JSON、ランタイム形式は仕様公開のゼロコピーバイナリ

- 状態: 採用
- 日付: 2026-10-30

## 背景

Live2D は編集形式（cmo3）と再生形式（moc3）を分けており、どちらも非公開である。Ravel は RON を使っているが、Seimei は Unity・Web・他言語・AI エージェントから読まれる。

## 決定

- プロジェクト形式: zip コンテナと展開ディレクトリの 2 形態。中身は JSON と PNG。JSON Schema を型から生成して公開
- ランタイム形式: ゼロコピーで読み込める独自バイナリ。仕様を CC-BY 4.0 で公開し、第三者実装を認める
- 両形式にメジャーバージョンと機能フラグ（無視可 / 必須）を持たせる
- 暗号化・難読化は v1 対象外

## 結果

- JSON は RON より冗長だが、外部ツールとの相性を優先した
