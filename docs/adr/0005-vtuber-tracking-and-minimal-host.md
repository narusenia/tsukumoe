# ADR-0005: VTuber 用途はトラッキング入力層と最小ホストで始める

- 状態: 採用
- 日付: 2026-10-30

## 背景

VTuber 配信では VTube Studio（内部は Cubism SDK）が事実上の標準で、Tsukumoe モデルを配信で使うには動かすアプリが要る。

## 決定

- ランタイム側にトラッキング入力層（VMC / OSC、iFacialMocap、MediaPipe）と標準パラメータマッピング（Live2D 慣習 ID + ARKit 52 blendshape）を持つ
- 最小のホスト（透過ウィンドウ、Spout2 / Syphon、仮想カメラ）を作る。M1 ではビューアとして始める
- 本格的なホストアプリは v2 を見込み、v1 中も動作確認に必要なら育てる
- 顔追跡の推論は外部・既存 SDK に任せ、自前で学習しない

## 結果

- moc3 から読んだモデルも、設定なしで追跡で動く
