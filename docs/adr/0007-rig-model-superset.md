# ADR-0007: リグモデルは Cubism の機能をすべて含み、ボーン・パラメータ式・物理チェーンを加える

- 状態: 採用
- 日付: 2026-10-30

## 背景

moc3 を損失なく読み込むには、Cubism モデルの機能をすべて表現できる必要がある。その上で、Live2D に対する差別化となる機能を選ぶ。

## 決定

- Cubism の機能をすべて表現できるデータモデルにする
- v1 で追加: ボーンと頂点ウェイトによるスキニング、パラメータ式（安全な小言語。Lua 等は使わない）、物理チェーン
- v1.x: IK・コンストレイント、擬似 3D、物理の衝突
- v2: 非格子パラメータ空間（RBF 等）
- 評価は固定段のパイプラインで、データ指向（SoA）に持つ
- Live2D 互換モードでは独自機能を無効にする

## 結果

- 評価段の順序（特にスキニングとデフォーマ、物理の再評価）を M1 で確定し、ADR に残す
