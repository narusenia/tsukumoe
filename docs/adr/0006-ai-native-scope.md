# ADR-0006: AI ネイティブ機能の範囲

- 状態: 採用
- 日付: 2026-10-30

## 背景

「AI ネイティブ」には、エージェント操作性・リグ支援・素材生成・モーション生成という性質の違う層がある。エージェント操作性はデータモデル設計の段階で前提にしないと後付けできない。

## 決定

- v1: 全編集操作のコマンド化と MCP / CLI 公開、ヘッドレスのレンダと検証、リグ支援（自動メッシュ・デフォーマとパラメータ雛形・物理設定）、リップシンク
- v1.x: テキストからのモーション生成
- v2 以降: 1 枚絵からのパーツ分割・補完
- 推論はプロバイダ差し替え式。既定はローカル（ONNX Runtime 等）、クラウドは明示設定時だけ。重みは同梱しない
- AI の出力は通常の編集コマンドとして適用し、undo と差分確認ができるようにする

## 結果

- すべての編集が `tsukumoe-core` のコマンド経由になる（REQ-CORE-007）
