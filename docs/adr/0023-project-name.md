# ADR-0023: プロジェクト名を Tsukumoe にする

- 状態: 採用
- 日付: 2026-10-30

## 背景

仮の名前 `Seimei` は、npm に同名のパッケージ（日本語の姓名分割ライブラリ）があり、GitHub にも別分野の同名プロジェクトがある。「生命・姓名」の一般語で、識別力も弱い。外に出る名前（拡張子、C ABI 接頭辞、パッケージ名）が増える M1-08 の前に変える。

## 決定

1. 名前は **Tsukumoe**（付喪 + 芽。古い物に魂が宿り、芽吹く）
2. 表記: 製品名 `Tsukumoe`、クレート・パッケージ・コマンドは `tsukumoe-*`、C ABI 接頭辞は `tsukumoe_`
3. ファイル拡張子: プロジェクト形式 `.tsukumoe`、ランタイム形式 `.tmod`（いずれも仮。M1-08 / M3 で確定）
4. `docs/handoff/` の過去の引き継ぎメモは、当時の名前（Seimei）のまま残す

## 根拠

候補 40 個余りを crates.io・npm・PyPI・GitHub で調べ、`tsukumoe` は 3 つのレジストリで空きで、GitHub に同名リポジトリも検索結果もない。英語の一般名詞は主要レジストリでほぼ使用済みだった。

## 結果

- クレート `seimei-core` を `tsukumoe-core` に改め、ライセンスヘッダの著作権表記も `Tsukumoe Contributors` にした
- GitHub のリポジトリ名の変更は別に行う（旧 URL からはリダイレクトされる）
- 商標・ドメインは未確認
