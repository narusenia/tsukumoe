# ADR-0024: 描画規則は premultiplied alpha・符号化値のまま合成・マスクは最大値で合成する

- 状態: 採用
- 日付: 2026-10-30

## 背景

描画リストは描画規則を持たない（M1-07）。レンダラの差し替え（REQ-RT-006）と環境間の一致（REQ-RT-007）のため、座標系・色の合成式・マスクの意味を仕様として固定する必要がある。

## 決定

1. **描画空間は Y 上向き。** 出力画像には矩形（ビュー）を指定して写す。画像の上端がビューの最大 Y
2. **UV は `v = 0` が画像の最上行。** ピクセル中心でサンプルする（バイリニア、端はクランプ）
3. **テクスチャは premultiplied alpha。** 読み込み時に、符号化されたままの値へ α を掛ける。sRGB のデコードはしない。合成は符号化値のまま、`Rgba8Unorm` の出力に行う（整数画像として環境間で一致させるため）
4. **乗算色・スクリーン色** は、乗算 → スクリーン → 不透明度の順に適用する（式は `rendering.md` 4）
5. **ブレンドは 3 種**（Normal・Additive・Multiply）。式は `rendering.md` 4
6. **マスクは集合の最大値**。マスクメッシュのテクスチャ α を描き、重なりは最大値。反転は集合全体に 1 回。マスクメッシュ自身のマスクは無視する（入れ子は 1 段）
7. **許容差** はチャンネルあたり 2/255、描画リストの数値差は 1e-4

## 結果

- Cubism との一致（乗算色・スクリーン色の式、マスクの合成、描画順の同値）は M2 で検証し、違えばこの ADR を改める
- 入れ子のマスクと、マスクが持つ不透明度の扱いは v1 では未対応
