# 物理の仕様

関連: REQ-CORE-005 / ADR-0022

状態: M1-06 の実装に合わせた Seimei 自身の定義。**Cubism（physics3）と一致するかは M2 で検証する**。定数（`GRAVITY_UNIT` など）は M2 の比較で調整しうる。

## 時間

- 固定刻み `STEP = 1/60` 秒。`Frame::advance(model, dt)` が `dt` を蓄積し、刻みの整数倍だけ進める。余りは持ち越す
- 1 回の `advance` で進める刻みは 10 まで。それを超える分は捨てる（長い停止の後に暴れない）
- `Frame::evaluate` は `dt = 0` と同じ。物理は進めず、現在の状態から出力を計算する
- 最初の評価では、全粒子を入力に合わせた静止姿勢に置く（初速 0）

## 入力

入力ごとに、パラメータ値 `v`（範囲に収めたもの）を `[min, default, max]` から、対象の範囲 `[lo, def, hi]` へ区分線形に写す。`default` が `def` に写る。

| 物理 | X / Y | 角度 |
|---|---|---|
| 振り子 | `position_range` | `angle_range` |
| チェーン | `[-1, 0, 1]` | `[-90, 0, 90]` 度 |

写した値に `weight / 100` を掛け（`reflect` なら符号を反転）、チャンネルごとに足す。結果が、平行移動 `T = (tx, ty)` と角度 `a`（度）。

## 振り子

粒子 0 は根で、位置は `rest[0] + T`。粒子 `i ≥ 1` は、親（`i - 1`）から `radius` の距離にある振り子。1 刻みで、

1. 重力の向き `g = (sin a, -cos a)`
2. `v ← (v + g · acceleration · 100 · STEP) · clamp(mobility, 0, 1)`
3. `eff = STEP · max(delay, 0.01)`、`p' = p + v · eff`
4. `p'` を、親から `radius` の距離の円へ寄せる（親と重なるときは `g` の向き）
5. `v ← (p' - p) / eff`

根が動くと、距離の拘束を通して粒子が引かれる。`mobility` は 1 刻みの速度の残り方、`delay` は粒子の時間の進み方、`acceleration` は重力の強さ（単位は `100` 倍）。

## チェーン

根は `T`。関節 `i` は親（`i = 0` は根）から `length` の距離にあり、静止の向き `rest` は `gravity` の向き（`gravity` がほぼ 0 なら下向き `(0, -1)`）を、角度 `a` だけ回したもの。1 刻みで、

1. `v ← (v + (gravity + wind) · STEP) · (1 - clamp(damping, 0, 1))`
2. `p' = p + v · STEP`
3. 親から `p'` への向きを、`rest` へ `stiffness`（0〜1）の割合で寄せ、親から `length` の距離に置く
4. `v ← (p' - p) / STEP`

初期姿勢は、根から `rest` の向きに垂れる。

## 出力

出力は、粒子 `k` の「親からの相対位置」 `rel = p_k - parent_k` から取る（親は、振り子では粒子 `k - 1`、粒子 0 では `rest[0]`。チェーンでは関節 `k - 1`、関節 0 では根）。

| チャンネル | 基準値 |
|---|---|
| X / Y | `rel` の成分 |
| 角度（振り子） | `atan2(rel.x, -rel.y)`（度。真下が 0、`+x` 側が正） |
| 角度（チェーン） | `rest` から `rel` への符号付き角度（度、反時計回りが正） |

値は `基準値 · scale`、`reflect` なら符号反転、さらに `weight / 100` を掛ける。出力パラメータは、評価の始めに既定値へ戻し、出力の値を足す（ADR-0022）。範囲に収めるのは通常の評価（手順 1）。

## コンパイルエラー

物理の出力パラメータにドライバの出力が重なるとき（`PhysicsOutputConflict`）。
