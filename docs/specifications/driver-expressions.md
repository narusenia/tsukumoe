# パラメータ式（ドライバ）の仕様

関連: REQ-CORE-004, REQ-CORE-008 / ADR-0007, ADR-0020

状態: M1-04 の設計。実装前。式言語は副作用のない安全な小言語で、汎用スクリプトは採用しない。

## 概要

`Driver` は出力パラメータ 1 つと式 1 つを持つ。式は他のパラメータの値から数を 1 つ求め、その値を出力パラメータの値にする。式はモデルのコンパイル時に 1 回だけ構文解析し、バイト列（スタック機械の命令列）にする。フレーム評価では命令列を実行するだけで、解析も確保もしない。

## 文法

```
expr    = term   { ("+" | "-") term }
term    = unary  { ("*" | "/") unary }
unary   = "-" unary | primary
primary = number | name | call | "(" expr ")"
call    = ident "(" [ expr { "," expr } ] ")"
```

- `number`: 10 進数（`1`、`0.5`、`1e-3`）。符号は単項マイナスで表す
- `name`: パラメータの永続 ID（`ParamAngleX`）。英字または `_` で始まり、英数字と `_` が続く
- 空白は無視する。コメント・文字列・変数代入・条件分岐・ループ・ユーザー定義関数はない

## 関数

| 関数 | 引数 | 意味 |
|---|---|---|
| `abs(x)` | 1 | 絶対値 |
| `min(a, b)` / `max(a, b)` | 2 | 小さい方 / 大きい方 |
| `clamp(x, lo, hi)` | 3 | `x` を `[lo, hi]` に収める。`lo > hi` なら `lo` |
| `lerp(a, b, t)` | 3 | `a + t·(b - a)` |
| `sin(x)` / `cos(x)` | 1 | 引数は度（回転デフォーマの角度と同じ） |

これ以外の関数名・引数の数はコンパイルエラー。関数の追加は仕様の変更で、バージョンを上げて行う。

## 意味

- 数はすべて `f32`
- `name` は、そのパラメータの値を、範囲に収める**前**の値で読む（ドライバの出力は読まれる側から見れば、すでに確定した値）
- 結果が `NaN` または無限大なら 0 にする（`x / 0` を含む）。ここで失敗やパニックにはしない
- 出力パラメータの値は、評価の手順 1 で通常のパラメータと同じく範囲に収める

## 依存と評価順

- ドライバの式が読むパラメータが、別のドライバの出力でもよい。コンパイル時に、読まれる側が先になる順（トポロジカル順）を求め、その順に実行する
- 循環はコンパイルエラー（自分自身を読む式を含む）
- 同じパラメータを出力とするドライバが 2 つ以上あるのはコンパイルエラー
- ドライバの出力パラメータには、呼び出し側が与えた値は使われない。式の結果で上書きする

## コンパイルエラー

| 種類 | 例 |
|---|---|
| 構文 | 閉じていない括弧、数字の途中の文字 |
| 未知の名前 | モデルにないパラメータ名、未知の関数 |
| 引数の数 | `clamp(x, 0)` |
| 循環 | `A = B`、`B = A` |
| 出力の重複 | 同じパラメータに 2 つのドライバ |
| 制限超過 | 下記 |

エラーはドライバの名前と、式の中の文字位置を持つ。

## 制限

- 式の長さは 1024 バイト以下
- 命令列のスタックの深さは 16 以下（コンパイル時に静的に求める）

## 命令列

- 命令: 定数の積み込み、パラメータの読み出し（コンパイル済みモデルのパラメータ配列の添字）、四則、符号反転、関数 7 種
- 全ドライバの命令列は、`CompiledModel` の 1 本の連続バッファに入れ、オフセット表で引く（ADR-0020）
- スタックは固定長配列で、ヒープを使わない

## 評価の手順での位置

[evaluation.md](evaluation.md) の手順 1 の前に、手順 0 としてドライバを評価順に実行し、出力パラメータの値を書き込む。

## 互換モード

Cubism にドライバはなく、互換モードでは無効（[data-model.md](data-model.md)）。互換モードの切り替え方は M1-04 の範囲外。
