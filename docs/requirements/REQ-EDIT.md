# EDIT 要件定義（エディタ）

対象クレート: `tsukumoe-app`。細部は M5 の着手時に詰める。

## REQ-EDIT-001: PSD 読み込み

| 項目 | 内容 |
|------|------|
| ID | REQ-EDIT-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

PSD のレイヤ構成をパーツとして取り込む。PSD を差し替えたとき、既存のメッシュ・リグを保ったまま画像だけを更新できる。

### 受入条件

- [ ] レイヤ・グループ・不透明度・ブレンドモード・非表示レイヤを読み込める
- [ ] PSD の再読み込みでレイヤ名による対応付けを行い、リグを保持する

### 依存要件

- REQ-FMT-001

## REQ-EDIT-002: メッシュ編集

| 項目 | 内容 |
|------|------|

| ステータス | Draft |

### 説明

### 依存要件

## REQ-EDIT-003: デフォーマとボーンの編集

| 項目 | 内容 |
|------|------|
| ID | REQ-EDIT-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ワープ・回転デフォーマの作成と階層編集、ボーンの作成と頂点ウェイトのペイント。

### 依存要件

- REQ-CORE-002
- REQ-CORE-003

## REQ-EDIT-004: パラメータとキーフォームの編集

| ID | REQ-EDIT-004 |

## REQ-EDIT-006: モーションと表情の編集

| 項目 | 内容 |
|------|------|
| ID | REQ-EDIT-006 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

タイムラインでのモーション編集（カーブエディタ付き）と、表情（パラメータの差分セット）の編集。

### 受入条件

- [ ] motion3 のカーブ種別（線形・ベジェ・ステップ・逆ステップ）をすべて編集できる
- [ ] リップシンク（REQ-AI-008）の結果をモーションとして取り込める

### 依存要件

- REQ-COMPAT-004

## REQ-EDIT-007: 書き出し

| 項目 | 内容 |
|------|------|
| ID | REQ-EDIT-007 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ランタイム形式と Inochi2D 形式で書き出す。Live2D 形式には書き出さない。

### 受入条件

- [ ] 書き出し前にモデル検査（REQ-AI-002）を実行し、問題を一覧する
- [ ] 書き出したランタイム形式を、その場のプレビューと同じ見た目で再生できる

### 依存要件

- REQ-FMT-004
- REQ-COMPAT-006
