# AI 要件定義（AI ネイティブ機能）

対象クレート: `seimei-ai` / `seimei-cli`

## REQ-AI-001: 全編集操作のエージェント公開（MCP / CLI）

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

編集コマンド（REQ-CORE-007）をすべて MCP サーバと CLI から実行できるようにする。エディタ起動中は、開いているプロジェクトにも同じコマンドを送れる。

### 受入条件

- [ ] UI からできる編集はすべて MCP / CLI からもできる
- [ ] コマンド一覧と引数のスキーマを MCP から取得できる
- [ ] エージェント向けの API リファレンスがコマンド定義から自動生成される

### 依存要件

- REQ-CORE-007

## REQ-AI-002: ヘッドレスのレンダと検証

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

エージェントが編集結果を自分で確かめられるよう、ウィンドウなしでレンダ・検証・差分取得を行える。

### 受入条件

- [ ] 指定したパラメータ姿勢の画像を CLI / MCP で出力できる
- [ ] 2 つの姿勢・2 つの版の画像差分を出せる
- [ ] モデルの検査（未使用パラメータ・壊れたメッシュ等）結果を構造化データで返す

### 依存要件

- REQ-RT-005

## REQ-AI-003: 推論プロバイダの抽象化

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

AI 機能の推論先を差し替えられるようにする。既定はローカル推論（ONNX Runtime 等）、クラウド API は利用者が明示的に設定したときだけ使う。

### 受入条件

- [ ] モデルの重みはアプリに同梱せず、初回利用時にダウンロードする
- [ ] 重みごとのライセンスを表示する
- [ ] クラウド送信が起こる機能は送信前に明示する

### 依存要件

- なし

## REQ-AI-004: AI 出力を編集コマンドとして適用

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-004 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

AI 機能の結果は通常の編集コマンド列としてモデルに適用する。中身の見えない生成物を作らない。

### 受入条件

- [ ] AI による変更を 1 回の undo で取り消せる
- [ ] 適用前に変更内容（コマンド列・画像差分）を確認できる

### 依存要件

- REQ-CORE-007

## REQ-AI-005: 自動メッシュ生成

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-005 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

パーツ画像の輪郭と形状から、変形に適したメッシュを自動生成する。

### 受入条件

- [ ] 頂点密度を指定して生成できる
- [ ] 目・口など変形が大きい部位で密度を上げられる

### 依存要件

- REQ-AI-004

## REQ-AI-006: デフォーマ配置とパラメータ雛形の生成

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-006 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

パーツ構成から、標準的なデフォーマ階層とパラメータ（目の開閉・口の開閉と形・顔の角度 XY・体の角度）の雛形を生成する。

### 受入条件

- [ ] 生成したパラメータの ID が Live2D 標準 ID に合い、REQ-TRK-002 の既定マッピングで動く
- [ ] 生成結果を人が修正する前提で、キーフォームの初期形を作る

### 依存要件

- REQ-AI-004
- REQ-AI-005

## REQ-AI-008: リップシンク

| 項目 | 内容 |
|------|------|
| ID | REQ-AI-008 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

音声から口のパラメータ（開閉・母音形）を生成する。マイク入力のリアルタイムと、音声ファイルからのモーション書き出しの両方を扱う。

### 受入条件

- [ ] リアルタイム時の遅延が 100 ms 以下である
- [ ] 日本語の母音（あいうえお）に対応する口形パラメータを出せる
- [ ] 音声ファイルから motion を生成できる

### 依存要件

- REQ-AI-003
- REQ-TRK-002
