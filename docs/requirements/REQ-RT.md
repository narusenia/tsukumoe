# RT 要件定義（ランタイム・バインディング）

対象クレート: `seimei-runtime` / `seimei-gpu` / `seimei-ffi` / `seimei-wasm`、別リポジトリの Unity パッケージ

## REQ-RT-001: 再生用ランタイム API

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

モデルを再生するための薄い API。ロード、パラメータ設定、モーション再生（レイヤ・フェード）、表情、物理ステップ、描画リスト取得を提供する。

### 受入条件

- [ ] 編集機能を含まず、`seimei-core` の評価部分だけに依存する
- [ ] モーションのクロスフェード・優先度・ループを扱える
- [ ] まばたき・呼吸などの自動動作を設定で有効にできる

### 依存要件

- REQ-CORE-006
- REQ-FMT-004

## REQ-RT-002: C ABI

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ランタイム API を C ABI で公開する。ヘッダは cbindgen で生成する。

### 受入条件

- [ ] ヘッダが自動生成され、CI で差分がないことを検査する
- [ ] パニックが FFI 境界を越えない（すべてエラーコードに変換する）
- [ ] C のサンプルプログラムが 3 OS でビルド・実行できる

### 依存要件

- REQ-RT-001

## REQ-RT-003: WASM と JS/TS パッケージ

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-003 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ランタイムを WASM にビルドし、TypeScript 型付きの npm パッケージとして配布する。描画は WebGPU、非対応環境では WebGL2 にフォールバックする。

### 受入条件

- [ ] WASM SIMD を有効にしたビルドを提供する
- [ ] WebGPU 非対応のブラウザで WebGL2 経路で表示できる
- [ ] 描画リストを JS 側の独自レンダラ（PixiJS 等）からも参照できる

### 依存要件

- REQ-RT-001
- REQ-RT-005

## REQ-RT-004: Unity パッケージ

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-004 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

Unity 向けのパッケージを別リポジトリで提供する（UPM 配布）。評価は `seimei-ffi` のネイティブプラグイン、描画は Unity のシェーダで行う。wgpu を Unity に持ち込まない。

### 受入条件

- [ ] 対応 Unity バージョンとレンダーパイプライン（Built-in / URP / HDRP）を仕様で決めている
- [ ] Unity 上の表示が wgpu 参照レンダラと REQ-RT-007 の基準で一致する
- [ ] Windows / macOS のエディタとスタンドアロンで動く

### 依存要件

- REQ-RT-002
- REQ-RT-006

## REQ-RT-005: wgpu 参照レンダラ

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-005 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

描画リストを wgpu で描画する参照実装。エディタ・ホスト・Web・CLI のレンダで共通に使う。外部から渡された wgpu device を使える。

### 受入条件

- [ ] クリッピングマスク・ブレンドモード・乗算色・スクリーン色・プリマルチプライドアルファを正しく描画する
- [ ] 外部 device（GPUI のもの）を受け取って描画できる
- [ ] ヘッドレス（ソフトウェアアダプタ）で画像を出力できる

### 依存要件

- REQ-CORE-006

## REQ-RT-006: レンダラの差し替え

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-006 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

描画リストだけを入力にすれば、どのエンジンでも描画できるようにする。描画規則（マスクの適用順・ブレンド式・色の合成式）を仕様として文書化する。

### 受入条件

- [ ] 描画規則が `docs/specifications/rendering.md` に定義されている
- [ ] wgpu 参照レンダラがその仕様に従っていることをテストで確認する

### 依存要件

- REQ-CORE-006

## REQ-RT-007: 環境間の出力一致

| 項目 | 内容 |
|------|------|
| ID | REQ-RT-007 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

ネイティブ・WASM・Unity で、同じモデル・同じ入力から同じ見た目が出る。

### 受入条件

- [ ] 描画リストの数値差が仕様で定めた許容誤差内である
- [ ] 最終画像の画素差分が閾値内である

### 依存要件

- REQ-RT-003
- REQ-RT-004
- REQ-RT-005
