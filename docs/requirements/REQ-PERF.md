# PERF 要件定義（性能）

計測環境: Apple M1 / 同等の中級 PC（Windows）。基準モデルは REQ-PERF-001。

## REQ-PERF-001: 基準モデルの定義と同梱

| 項目 | 内容 |
|------|------|
| ID | REQ-PERF-001 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

性能目標と互換検証に使う基準モデルを自作し、CC-BY 4.0 でリポジトリに同梱する。
規模: ArtMesh 150 / 頂点 3 万 / パラメータ 100 / デフォーマ 80 / 物理 20 系統。

### 受入条件

- [ ] Tsukumoe 形式と、Cubism Editor で作った同等の Live2D 形式の両方がある
- [ ] 規模が上記を満たす

### 依存要件

- なし

## REQ-PERF-002: ネイティブの評価時間

| 項目 | 内容 |
|------|------|
| ID | REQ-PERF-002 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

基準モデルの 1 フレーム評価（パラメータ入力から描画リストまで）を、1 スレッドで 0.5 ms 以下にする。
v1 は CPU と SIMD で達成を狙い、未達のときだけ GPU 変形を検討する。

### 受入条件

- [ ] criterion ベンチマークで中央値が 0.5 ms 以下である

### 依存要件

- REQ-PERF-001
- REQ-CORE-008

## REQ-PERF-003: WASM の評価時間

## REQ-PERF-006: 多数体の同時表示

| 項目 | 内容 |

| ID | REQ-PERF-006 |
| 優先度 | Should |
| ステータス | Draft |

## REQ-PERF-007: Cubism SDK 比の評価速度

| 項目 | 内容 |
|------|------|
| ID | REQ-PERF-007 |
| 優先度 | Must |
| ステータス | Draft |

### 説明

同じ基準モデル（Live2D 形式版）で、Cubism SDK の評価時間の半分以下にする。
比較は手元での検証に限る。比較結果を公開してよいかは SDK ライセンスを確認してから決める。

### 受入条件

- [ ] 手元計測で Cubism SDK 比 2 倍以上速い
- [ ] 計測手順を `docs/dev/` に記録している（結果の数値は公開可否が決まるまでリポジトリに入れない）

### 依存要件

- REQ-PERF-001
- REQ-PERF-002
