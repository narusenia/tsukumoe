# Icons

Selected icons from [Lucide](https://lucide.dev) 1.65.0 (ISC; see `LICENSE`).
Each file is the upstream SVG with one change: `stroke="currentColor"` is
`stroke="#ffffff"`, so the UI can tint the rendered icon with the theme color.
To add an icon, copy the upstream SVG here, make the same change, and list it
in `src/icons.rs`.
